ToothFairy Viewer 1.05

실제 도시 모델에서 재현한 CPU 준비 작업을 줄였습니다.
- 표시 패스를 모두 꺼도 매번 실행되던 객체 상태 검사와 화면 안팎 판별을 건너뜁니다.
- 텍스처·선만 표시할 때 불필요한 그림자 상태 검사를 건너뜁니다.
- 태양 조명이 설정되어 있어도 관련 패스를 껐으면 불필요한 검사를 하지 않습니다.
- 필요한 객체 검사는 그대로 유지하면서 메모리를 미리 읽어 CPU 대기를 줄였습니다.
- CPU 모델명과 CPU/GPU 판별 입력량, 실제 검사 실행 여부를 성능 로그에 기록합니다.

제조사별로 기능이나 품질을 낮추지 않습니다. 텍스처 해상도·그림자 품질은 유지합니다.
이전 업데이트 복구가 포함됩니다. 이번 측정은 렌더러 CPU 구간이며 앱 전체 FPS가 아닙니다.
친구 PC의 모든 지연 원인이 해결됐다고 확인된 것은 아닙니다.
