ToothFairy Viewer 1.07

불필요한 재계산 개선 1~15
1. 재질·하늘 변경 시 필요한 화면 정보만 갱신합니다.
2. 선택 표시만 바뀌면 기존 장면 화면을 재사용합니다.
3. 변환 행렬이 바뀌지 않은 객체의 반복 비교를 생략합니다.
4. CPU 그리기 대상 분류와 GPU 화면 밖 제외 결과를 재사용합니다.
5. 편집 가이드에 필요한 깊이 화면을 재사용합니다.
6. 바뀌지 않은 조명 계산과 GPU 전송을 생략합니다.
7. 선택 위치 주변 객체만 정밀 검사합니다. 면·선·꼭짓점 선택을 포함합니다.
8. 선택된 면의 위치를 색인으로 찾습니다.
9. 변하지 않은 객체의 경계 상자를 재사용합니다.
10. 대기 상태의 선택 목록·화면 상태 복사를 줄입니다.
11. 텍스처 메모리 사용량과 알파 분류의 반복 계산을 줄입니다.
12. 내보내기 시 바뀐 변환만 동기화합니다.
13. 내보내기 패스들이 공통 장면 준비 결과를 공유합니다.
14. 캐릭터 변경 시 해당 부분만 직접 찾습니다.
15. HUD 내용이 같으면 그리기를 생략하고 편집 애니메이션은 유지합니다.

텍스처 해상도·알파·그림자 품질과 Live2D 로딩을 유지합니다.
기존 DPI별 MSAA 선택 정책은 유지합니다.
픽셀·선택·저장 회귀 검사와 MSAA 8배, UI 배율 100/125/150/200% 검사를 통과했습니다.
진단 로그에 화면·깊이·객체 분류·선택 색인의 생성/재사용 누적 횟수를 추가했습니다.
측정은 로컬의 해당 CPU 작업 결과이며 친구 PC의 FPS 개선은 아직 실측하지 않았습니다.
