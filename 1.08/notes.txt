ToothFairy Viewer 1.08

1. 선택 표시의 깊이 화면 생성에 이미 계산한 표시 대상 목록을 재사용합니다.
   첫 선택에서 화면 밖 객체까지 다시 제출하던 중복 작업을 줄였습니다.
2. 회전·이동 시 숨겨진 부품의 표시 대상 분류를 생략합니다.
3. 부품별 캐시 확인용 임시 메모리 할당을 고정 크기 비교로 교체했습니다.
4. Original 화면 보관용 깊이 버퍼의 중복 할당·복사를 제거했습니다.
   선택 가이드용 깊이와 MSAA 샘플 수는 유지합니다.
5. 마우스 입력·면/선/꼭짓점 정밀 검사·선택 표시 깊이 생성 시간을 로그에 기록합니다.

검증: MSAA 8배 선택 화면 픽셀 비교, 숨김 부품 및 8192개 배치,
캐시 무효화 7종, 실제 대형 SKP 동일 조건 비교, EXE 셰이더 컴파일,
업데이트 보조 파일 복구·교체·재시작 검사를 통과했습니다.

로컬 2560x1340, MSAA 8배, 텍스처·선 표시에서:
회전 CPU 처리 평균 28.45ms → 20.48ms,
GPU 완료 대기 포함 평균 66.03ms → 57.24ms.
깊이를 새로 만드는 선택 표시 평균 192.35ms → 15.95ms.
전체 앱 입력 지연이나 친구 PC의 FPS 측정값은 아닙니다.

텍스처·그림자 품질과 Live2D 로딩을 유지합니다.
그림자를 켠 상태의 GPU 표면 처리 비용은 남아 있으며,
이번 수정이 모든 회전 지연을 해결한다는 의미는 아닙니다.
