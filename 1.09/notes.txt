ToothFairy Viewer 1.09

1. 회전으로 바뀐 그림자 객체의 변환만 갱신합니다.
   정적인 도시 전체의 배치 복사·중복 검사를 줄였습니다.
   이동·변형·숨김·계층 편집에 필요한 갱신은 유지합니다.
2. 같은 위치·카메라·모델·설정의 반복 선택 결과를 재사용합니다.
   객체 이동, 숨김, 외형, 카메라, 설정 변경 시 다시 검사합니다.
3. 그리기 묶음 안에서 같은 재질·면 방향·투명도 상태를 GPU에
   반복 전달하지 않습니다. 각 패스의 첫 설정은 항상 적용합니다.
4. 선택 검사·재사용 및 부분 그림자 갱신 횟수를 로그에 추가했습니다.

실제 Koki 도시 SKP, 사용자 로그와 같은 카메라,
1920x1000, MSAA 8배, 텍스처·선·음영·그림자 조건에서
그림자 장면의 CPU 갱신 평균 18.49ms → 1.30ms.
인접한 수정 전후 화면 픽셀 비교를 통과했습니다.
288개 선택 결과, 반복 선택과 무효화, 그림자 CPU/GPU 데이터,
16개 재질 상태와 81개 그림자 화면, 선택 표시 깊이, 실행 파일의 컴파일러와
업데이트 복구·교체·재시작을 검증했습니다.

텍스처·그림자·MSAA 품질과 Live2D 로딩을 유지합니다.
GPU 그림자 계산과 첫 선택 시 진행 중인 GPU 작업 대기는 남아 있습니다.
위 수치는 그림자 장면 갱신 부분의 CPU 시간이며 전체 프레임 시간이나
친구 PC의 FPS가 아닙니다. 모든 지연이 해결됐다는 의미는 아닙니다.
