ToothFairy Viewer 1.13 — Koki 그림자 조작 최적화 검증 빌드

수정:
- 화면 뒤에 가려진 면에서 수행하던 그림자 광선 검사를 보수적으로 생략.
- MSAA 전체 깊이 샘플과 면의 기울기를 확인해, 가려짐이 확실한 경우에만 생략.
- 조작 미리보기와 본 장면의 겹친 수신 면에 적용. 그림자·해상도·MSAA·텍스처 품질 유지.
- 로그에 미리보기 깊이 처리/광선 검사 GPU 시간과 선택 대상 ID, 검사 활성 여부 추가.
- 1.12의 Done 이후 수동 방향 유지 수정 포함.

실제 모델 검증:
- 지정된 Koki 판타지 눈의 도시_006화(할리아스용 수정본).skp, 119,069,969바이트.
- 전체 604,554개 노드, 15,387개 파트. 115,821개 하위 노드를 가진 그룹의 그림자 미리보기 검사.
- 1920×1000, MSAA 8배: 미리보기 약 95ms → 42ms. 장면+미리보기 약 189ms → 135ms(약 29% 감소).
- 2560×1340, MSAA 8배, 사용자 로그 시점/낮은 그림자 각도: 미리보기 약 198~252ms → 106~107ms.
- 두 시점의 10개 방향에서 최적화 켜짐/꺼짐 픽셀 차이 0. 실제 미리보기 색이 나타나는 것도 검사.
- 투명·잘린 텍스처·겹친 면 등 그림자 81개 비교와 정방향/역방향 깊이의 미리보기 비교 통과.
- Done/Esc/Enter 후 카메라 120프레임 방향 유지, 큰 면 깊이 및 배포 EXE 셰이더 컴파일 검사 통과.

측정 범위:
- 위 시간은 로컬 GPU에서 동기적으로 렌더링 완료를 기다린 검사 결과이며 전체 앱 입력/창 표시 지연은 포함하지 않음.
- 큰 해상도 검사 중 본 장면 시간 변동이 있어 전체 FPS 향상 수치로 환산하지 않음.
- 본 장면 렌더링 비용은 여전히 남아 있음. 다른 PC의 동일 성능 및 모든 시점의 무지연을 보장하지 않음.
- GitHub 업데이트 정보는 1.13을 가리키도록 게시합니다.
