ToothFairy Viewer 1.17

- 카메라 이동 후 선 패스 아래쪽/일부 영역이 흰 그라데이션처럼 지워지던 문제 수정. 반투명 면의 가림 처리가 이전 카메라 행렬 및 다른 패스 상태를 사용하지 않도록 명시적으로 초기화합니다.
- 1.16에서 도입한 미검증 자동 상자 변환을 되돌렸습니다. 회전, 이동, 레이어, 캐릭터, 그림자 조작 중에도 실제 형상과 해당 패스를 표시합니다. 기존 그림자 깊이 캐시와 텍스처 메모리 최적화는 유지합니다.
- 그림자 농도, 색감, 선 두께, 불투명도, 해상도 및 MSAA 설정은 변경하지 않습니다.

검증: 선/반투명/카메라 조합 12개 통과(수정 전 8개 실패). 실제 Koki 모델 1920x1000 MSAA 8에서 카메라 4개와 선/그림자/음영의 화면·내보내기 24개 조합 모두 기준 결과와 픽셀 차이 0. 깊이 상태, 그림자 미리보기와 핸들 표시, 업데이트 교체·복구 검사 통과.

공식 API 확인: Desktop SDK는 SKP 읽기/쓰기 API이며 스케치업 내부의 조작 중 프록시 표시 엔진을 호출하는 공개 API는 제공하지 않습니다. 1.16의 별도 상자 구현을 스케치업과 동일한 방식이라고 설명한 것은 부정확했습니다. 이번 배포를 동일 프록시 구현 완료나 저사양 성능 개선 완료라고 주장하지 않습니다. 잘못된 상자 변환을 되돌려 실제 형상을 표시하므로 해당 표시 비용은 남습니다.
https://developer.sketchup.com/

이 배포본은 미서명이며 Smart App Control 허용을 보장하지 않습니다. 구버전 업데이트 도우미에서 교체가 실패하면 새 EXE를 직접 받아 기존 뷰어 종료 후 교체해야 할 수 있습니다. 업데이트 실패 로그: viewer_update_apply.log.
