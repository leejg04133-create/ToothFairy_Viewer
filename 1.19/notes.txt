ToothFairy Viewer 1.19

- Shift+Tab을 누른 뒤 Shift를 먼저 떼거나 같은 Tab 입력이 다시 전달되어도, Tab을 뗄 때까지 오른쪽 메뉴 동작으로 바뀌지 않도록 한 번의 누름만 처리합니다. Tab을 새로 누르면 오른쪽 메뉴는 정상 작동합니다.
- 왼쪽 메뉴 펼침·접힘 시 기존 오른쪽 메뉴 화면을 옮겨 보이던 잔상을 수정했습니다. 새 그림과 창 위치·크기를 동시에 반영하고, 양쪽 메뉴 상태가 달라지면 부분 갱신 대신 화면을 새로 구성합니다. 포커스 이동과 그리기는 반대쪽 메뉴의 열림 상태를 덮어쓰지 않습니다.
- 카메라 방향 그림자 고정 상태에서 조작을 멈출 때 오래 멈추던 병목을 수정했습니다. 화면을 향하는 객체의 위치 매칭을 전체 이동 캐스터 검색에서 전용 검색 구조로 분리했습니다. 검색 순서와 위치 변환은 유지하고 이동 시 경계만 갱신합니다.
- 실제 야구장 파일과 저장된 그림자 고정·음영 분리 설정, 1920×1000/MSAA 8배에서 검색 노드 184,879→143개, 같은 두 시점의 원본 GPU 프레임 1,599~1,960ms→44~56ms를 확인했습니다. 여섯 번의 이미지 비교 모두 픽셀 차이 0입니다. 이 수치는 이 PC/파일/시점의 측정값입니다.
- 화면 왼쪽 아래에 카메라 조작 패드를 추가했습니다. 세로/가로 슬라이더와 두 축 조이스틱이 기존 방향키 카메라 동작 및 조작 속도를 사용합니다.
- 손을 놓으면 핸들이 부드럽게 중앙으로 복귀하고 짧게 감속합니다. 포커스 상실·Esc·창 숨김 시 카메라 움직임을 취소합니다.
- 세 아이콘 영역에서 휠 또는 클릭으로 모드를 변경합니다. 기본은 방향키 회전, 두 번째는 Ctrl 방향키의 롤/화각, 세 번째는 Shift 방향키의 이동입니다. 선택 아이콘은 곡선을 따라 큰 중앙 위치로 이동합니다.
- Ctrl 모드의 두 축 조이스틱은 사용할 수 없습니다. 누르면 빨간 흔들림으로 표시하며, 롤과 화각은 각각의 슬라이더로 조작합니다.
- 기존 E/R/T 도구 아이콘을 사용합니다. 검게 보이던 T 커서는 흰색과 어두운 테두리로 수정했습니다. 설명 문구와 아이콘 뒤 배경 박스는 제거하고 큰 빈 원형 핸들과 얇은 레일을 적용했습니다.
- 롤 좌우 방향을 키보드와 패드 모두에서 수정했습니다. 가운데 아이콘을 키우고 조이스틱 중심을 기준으로 양쪽 바와 아이콘을 반사 대칭 배치했습니다. 가운데 연결 곡선은 제거하고 바 두께를 정리했습니다.
- 기존 아래 메뉴(라이트·캐릭터·크랙·셰이더·유틸)를 왼쪽 세로 메뉴로 이동했습니다. 바는 양쪽에 고정하고 개별 메뉴 아이콘만 길게 눌러 반대쪽으로 이동하거나 순서를 바꿀 수 있습니다. 아이콘 위치를 저장하며 왼쪽 서브메뉴는 카메라 패드, 오른쪽은 HUD 영역을 비워 둡니다. Esc·잘못된 위치·캡처 상실 시 이동을 취소합니다.
- Tab은 오른쪽 메뉴와 HUD, Shift+Tab은 왼쪽 메뉴를 접고 펼칩니다. 양쪽의 선택 항목·열림 상태·스크롤을 따로 유지하며 두 서브메뉴를 동시에 열 수 있습니다.
- 로딩 오버레이를 띄우기 전에 카메라 패드를 즉시 숨기고 입력을 취소합니다. 로딩 중 타이머나 화면 갱신으로 다시 나타나지 않습니다.
- Ctrl+위·아래 및 화각 슬라이더로 조절할 때 중앙 화각 값을 표시합니다. 조절 직후 숫자를 입력하고 Enter를 누르면 Z와 동일하게 적용하며, 오른쪽 HUD를 접어도 화각 입력을 사용할 수 있습니다.
- 손을 놓은 뒤 200ms 동안 다시 잡으면 같은 프록시 조작을 이어 갑니다. 느린 프레임 직후에도 해제를 처리한 시점부터 기다려 짧은 정지마다 원본 복원 프레임이 끼어드는 것을 줄였습니다. 휠은 기존 450ms 유지합니다.
- 메뉴 부분 갱신은 변경된 영역만 그려 올리고 변경 없는 WM_PAINT는 저장된 화면을 다시 전송하지 않습니다. 가만히 있는 카메라 패드는 다시 그리지 않습니다. 패드와 왼쪽 메뉴 그리기 시간도 성능 로그에 분리 기록합니다.
- 카메라 패드도 기존 화면 프록시 경로를 사용합니다. 패드는 이미지 내보내기에 포함되지 않습니다. 재질·패스·그림자 농도·투명도·출력 설정을 바꾸지 않고 검색 대상만 줄였습니다. 저사양 PC의 성능은 실측하지 않았습니다.

검증: 100/125/150/200% 배율의 native 입력 및 표시, 키보드 12방향 일치, 스프링, Ctrl 두 축 차단, 프록시 활성·재조작·복원, 메뉴 이동·취소·저장·양쪽 Tab, 화각 표시·숫자 입력, 흰색 T 커서. 부분 갱신/전체 갱신 픽셀 동일. 메뉴 부분 갱신 평균 1.8323→1.03583ms, 변경 없는 갱신 0.249812→0.0179467ms(이 PC의 동일 테스트). 전체 메뉴 갱신 약 15ms와 원본 복원 GPU 비용이 모두 사라졌다는 의미는 아닙니다.
