- SketchUp에서 복사한 오브젝트를 뷰어에 붙여넣을 때, 별도 연동 플러그인에 현재 선택 전송을 요청하던 의존성을 제거했습니다. Windows 클립보드에 복사된 SKP 스냅샷 자체를 읽습니다. 특정 SketchUp 연도로 제한하는 조건은 없습니다.
- 붙여넣은 스냅샷은 기존 삽입·배치 경로로 가져옵니다. 복사 후 SketchUp 선택이 바뀌거나 여러 버전이 실행돼 있어도 다른 현재 선택을 가져오지 않습니다.
- SDK 파일에서 읽은 동적구성요소 동작을 실행부에 연결하지 않던 회귀를 수정했습니다. 기존 지원 범위의 회전·이동·숨김, ANIMATE/SET 동작과 종속 숨김 상태를 다시 연결합니다. 알 수 없는 수식이나 임의 Ruby 코드는 실행하지 않습니다.
- 함께 선택한 동적구성요소의 우클릭 재생과 직접 잡아 조작하기, 각자의 축 기준 동작, 취소·놓기·빠른 우클릭 두 번 초기화를 검사했습니다.
- 일반 숨김과 동적 동작에 따른 숨김은 분리합니다. 일반 숨기기 해제로 비활성 부품이 나타나지 않으며, 초기화 시 문과 종속 부품은 동적 초기 상태로 돌아갑니다. 사용자가 별도로 숨긴 오브젝트 상태는 유지합니다.
- 단일 SET("hidden",1) 동작이 값 개수 조건에 막히던 문제와, 열린 상태로 저장한 자식의 회전값을 잘못 적용하던 문제를 수정했습니다.
- 동적 숨김 전환 시 전체 탐색 인덱스를 다시 만들던 불필요한 작업을 제거했습니다. 위치·회전 변경은 기존 부분 갱신을 사용합니다.
- 텍스처 색감·앞뒷면·불투명도·선 두께·그림자·내보내기 설정은 변경하지 않았습니다. 1.22의 단일 SDK 읽기와 무손실 압축 개선을 유지합니다.

검증 범위:
- 공식 SDK의 버전별 저장 기능으로 만든 2017~2020 형식과 2021 이후 공통 형식을 대상으로, 헤더 위치 5종씩 총 50개 클립보드 읽기·실제 SKP 해석 검사를 통과했습니다. Windows의 실제 클립보드는 변경하지 않았습니다.
- 이 PC의 설치된 SDK 읽기 라이브러리 9개로 형식 호환성을 확인했습니다. 실제 SketchUp 앱 10개에서 Ctrl+C/V를 모두 수행했다는 의미는 아닙니다. 앱 UI 검증은 사용자의 Esc 중단으로 완료하지 않았습니다.
- 실제 SDK 속성을 포함한 파일의 동작 추출 → 뷰포트 우클릭 콜백 → 문 회전·종속 숨김 전환 → 초기화를 검사했습니다. 붙여넣기와 같은 병합 경로로 삽입한 두 구성요소의 동시 동작도 통과했습니다.
- 카메라·축척·직교·화면 배율·복수 선택·취소·놓기 검사와 텍스처·UV·저장/재열기 SDK 회귀 검사를 통과했습니다.
- 모든 SketchUp 동적 수식을 재현하는 일반 수식 엔진은 아닙니다. 기존 뷰어가 지원하던 동작 범위의 연결을 복구한 수정입니다.
