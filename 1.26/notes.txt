빌드 식별: 20261026-copy-paste-move-1.26

변경:
- 이동·회전 도중 Ctrl을 누르는 경우와 잡기 전에 미리 누르는 경우 모두 복사 모드가 동작합니다. Ctrl을 놓아도 현재 모드를 유지하며 다시 누르면 전환하는 기존 방식을 유지합니다. Ctrl+V로 생성한 대상을 놓을 때 추가로 복사하지 않습니다.
- 내부 복사/붙여넣기와 Ctrl 이동·회전 복사는 선택한 하위 구조와 연결된 파트만 복제·동기화합니다. 배경 전체의 변환과 정점 경계를 다시 계산하던 작업을 제거했습니다. 동일한 메시·텍스처는 계속 공유합니다.
- 조작 중 스냅은 기존 공간 검색으로 커서에 걸리는 후보만 검사합니다. 이후의 삼각형 교차, 꼭짓점/중점/변 스냅 우선순위와 동률 순서는 유지합니다. 선택 대상 경계는 압축된 위치를 한 번씩 읽어 정확히 구합니다. 회전·반전·기울임에 부정확한 상자 근사를 사용하지 않습니다.
- 이미 선택한 객체의 이동/회전 시작과 놓기에서 쓰지 않던 선택 검사를 생략합니다. 객체 조작 때문에 무관한 배경의 루트 메시를 분리하지 않습니다. 실제 면·선 편집 경로는 유지합니다.
- 복사할 때 배경 검색 트리를 다시 만들지 않습니다. 기존 인스턴스의 정적 트리를 유지하고 새 복사본만 추가합니다. 같은 메시를 쓰는 배경 전체를 선형 검색 대상으로 옮기지 않습니다.
- SketchUp 데이터 붙여넣기와 팔레트 배치는 새 하위 구조/파트만 합칩니다. 배경 GPU 메시·텍스처·공간 검색 데이터를 유지하고 중복 업로드를 제거했습니다. 동적 구성요소와 항상 카메라를 향하는 카드도 가져온 범위만 갱신합니다. 팔레트 지지점 경계는 이미 구한 값을 재사용합니다.
- 복사된 동적 구성요소의 동작 정보와 현재 값을 연결해 별도로 조작할 수 있습니다. 열린 문을 복사한 뒤 닫을 때 회전이 중복되지 않도록 현재 자세를 기준으로 동작합니다.
- 실행 취소/다시 실행에서 가시성만 바뀌는 복사본은 전체 변환과 GPU 인스턴스를 다시 올리지 않습니다. 바뀌지 않은 변환도 재업로드하지 않습니다.
- 텍스처 색·앞뒷면·불투명도·그림자 농도·선 두께·내보내기 품질은 변경하지 않습니다. 1.25 메뉴/단축키/음영 방향 미리보기도 유지합니다.

검증:
- 실제 앱의 숨긴 OpenGL 4.6 창과 입력 콜백에서 이동/회전 × Ctrl 선행/중간/끄기/재활성화 8조합, 복사본 원래 자세, 선택 유지, 실행 취소/다시 실행을 통과했습니다.
- 다중 선택, 서로 다른 부모, 반전 변환, 투명 텍스처, 내부 붙여넣기, 실제 SDK 스냅샷의 앱 붙여넣기·팔레트 배치를 검사했습니다. 6상황 × 원본/선/텍스처/재질/음영/그림자/깊이 7패스 = 42개 이미지가 새 전체 GPU 업로드 결과와 픽셀 단위로 일치했습니다.
- 실제 Koki 모델(604,554 노드, 15,387 파트)을 GPU에 올린 뒤 Ctrl 이동·회전 복사, 내부 붙여넣기, 네이티브 데이터 붙여넣기, 팔레트 배치를 통과했고 배경 검색 트리 재생성이 없었습니다.
- Koki의 같은 24개 스냅 검색은 이전 전체 순회 코드와 결과가 같고 합계 약4,135ms에서4.98ms로 줄었습니다. 선택 대상(9,816 논리 정점)의 경계는 평균약143ms에서0.045ms로 줄었습니다. 원문은 validation.json에 보관합니다.
- GPU가 연결된 Koki 입력 검사에서 내부 붙여넣기는 약3ms, 이동·회전 갱신 처리는 약2~4ms였습니다. 최초 Ctrl 복사는 큰 노드/소유자 배열의 메모리 확장으로 약45ms가 남고, 이후 회전 복사 확정은 약2.6ms였습니다. 입력/변환/업로드 호출 구간 측정이며 전체 화면 FPS나 모든 PC의 무지연 보장은 아닙니다. 네이티브/팔레트 시간은 작은 SDK 카드로 측정했고 큰 외부 SKP의 읽기 시간은 입력에 따라 다릅니다.
- CPU 전용 검사는 최초 검색 트리 준비를 포함해 이전 평균붙여넣기1,196ms에서447ms로 줄었고, 준비 후 반복은 약2.8ms였습니다. 실사용 GPU 검사와 구분합니다.
- SDK 저장/재열기·태그·구조 복제/삭제·이미지/재질/불투명도, 면·선 변형/실행 취소, 동적 숨김/우클릭, 단축키 검색/화각 입력, 음영 미리보기72조합을 다시 검사했습니다. 클립보드는 5개 접두 형식을 검사하고 사용자 Windows 클립보드는 바꾸지 않았습니다. 이번에 모든 연도별 SketchUp 앱을 직접 조작한 검사는 아닙니다.
