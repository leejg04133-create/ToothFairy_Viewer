ToothFairy Viewer 1.27 — 셰이더 GPU 처리 최적화

- 공통 후처리의 효과 분기를 링크 시 고정하여 툰·유화·망가·색상·윤곽·톤 처리에 필요한 GPU 코드만 실행합니다. 효과별 프로그램은 재사용하며 매 프레임 다시 컴파일하지 않습니다.
- 유화의 방향 계산·가로/세로 적분·페인트 처리를 각각의 GPU 프로그램으로 분리했습니다. 반경, 반복 횟수, 표본, 필터 수식, 색상·알파는 유지합니다.
- 색연필 표면 탐색의 불필요한 분기를 제거하고 uniform 위치를 캐시했습니다. 이미 만든 이동 맵을 사용하는 단계는 별도 분리의 이득이 없어 기존 GPU 연산 코드를 유지했습니다.
- 카메라 프록시, 그림자 농도·투명도, 텍스처 색감, 선 두께, 출력 해상도·안티앨리어싱과 기존 내보내기 방식은 변경하지 않았습니다. 좌측 메뉴 복구 및 셰이더 재클릭 시 기본값 복귀도 유지합니다.

출력 검사:
- 단일 효과 80가지, 프리셋 조합 96가지, 색연필 번짐·불투명도·배율·크기 변경 30가지, 실제 Koki 모델의 기본/유화/망가/색연필 × 원본/선/텍스처/재질/음영/그림자/깊이 28가지 = 234가지 RGBA 픽셀 비교가 이전 구현과 완전히 일치했습니다.
- GPU 오류 0. 준비 이후 공통 후처리의 uniform 이름 반복 조회도 0회입니다.

성능 측정 범위:
- 이 PC의 NVIDIA OpenGL 4.6 드라이버에서 준비 후 6회 교차 측정한 중앙값입니다. 전체 뷰어 FPS나 모든 PC에서의 개선율을 뜻하지 않습니다.
- 툰 후처리 1920×1080: 0.0713ms → 0.0494ms, 약 30.7% 감소.
- 유화 후처리 1920×1080: 9.3128ms → 8.3026ms, 약 10.8% 감소.
- 망가 후처리 1920×1080: 0.1746ms → 0.0819ms, 약 53.1% 감소.
- 색연필 표면 탐색 640×400: 0.6678ms → 0.5947ms, 약 10.9% 감소. 재사용 단계의 작은 차이는 변동 범위로 봅니다.
- 색연필 기존 이동 맵 재사용 640×400: 0.2995ms → 0.2943ms, 약 1.8% 감소. 재사용 단계의 작은 차이는 변동 범위로 봅니다.
