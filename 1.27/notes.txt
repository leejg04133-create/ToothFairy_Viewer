ToothFairy Viewer 1.27 — 색연필의 가시성 재계산 중복 제거

색연필의 내부 좌표 맵은 내보내기 모드로 그린 뒤 실제 화면은 일반 모드로 그립니다. 그때마다 표시 결과가 같아도 가시성 캐시를 초기화하여, Koki 모델에서 구성요소별 가시성 규칙을 반복 생성하던 문제를 수정했습니다.

- 캐릭터 내보내기 제외, 화면에서 특정 캐릭터 숨김, 구성요소 편집 컨텍스트처럼 실제 가시성이 달라지는 조건은 계속 정확히 구분합니다. 숨김·레이어·삭제 변경도 기존 변경 감지로 갱신합니다.
- 깊이·하늘·앰비언트와 모든 패스를 끈 원본 화면은 색연필 좌표 맵을 사용하지 않으므로, 전체 모델을 추가로 그리던 준비 작업을 생략합니다.
- 텍스처 색감, 그림자 농도, 선 두께, 투명도, 내보내기 해상도·안티앨리어싱과 색연필 무늬는 변경하지 않았습니다. 앞선 효과별 GPU 최적화와 셰이더 재클릭 시 기본값 복귀, 좌측 메뉴 수정도 유지합니다.

최종 검사:
- 단일 효과 80, 프리셋 96, 색연필 파라미터/크기 30, 실제 Koki 모델의 4가지 스타일 × 7패스 28 = 기존 RGBA 비교 234가지를 재실행하여 모두 일치했습니다.
- 원래 가시성 분류 코드와 180회 비교하여 캐릭터 내보내기 제외, 편집 컨텍스트, 선택 숨김, 레이어·삭제·숨김 변경을 확인했습니다.
- 실제 Koki의 같은 화면과 6개 이동 투영에서 수정 전후 픽셀이 완전히 일치합니다. 좌표 맵을 사용하지 않는 4가지 화면도 수정 전후 RGBA가 같습니다. GPU 오류 0.

이 PC에서 Koki(604,554 노드), 640×400, 프록시 없이 전체 품질로 6회 렌더링·CPU 읽기를 포함해 측정했습니다. 다른 GPU 작업 등 실행 환경에 따라 시간은 달라지며 실시간 조작 FPS를 직접 측정한 값은 아닙니다.
- 같은 화면 평균: 358.3ms → 176.5ms. 가시성 캐시 재생성 12회 → 0회.
- 이동 투영 평균: 339.2ms → 179.5ms. 가시성 캐시 재생성 12회 → 0회, 인스턴스 가시성 규칙 재생성 183,408회 → 0회.

버전은 1.27 유지. 이전 버전은 설정 → 업데이트. 이미 1.27이면 새 EXE를 받아 기존 창을 닫고 교체 후 실행하세요.
