ToothFairy Viewer 1.28 수정본 — 선택 객체 HUD / 기존 오른쪽 HUD 복구

- Alt로 여는 재질 바와 같은 스타일의 하단 고정 선택 객체 HUD를 추가했습니다. 이름·개수·선택 목록, 이동·회전·숨기기·단독 보기와 선택·그룹·그림자·편집 아이콘을 제공합니다.
- 목록과 카테고리 팝업은 해당 아이콘 위로 열리며 한 번에 하나만 표시됩니다. 편집의 복사·붙여넣기·오려내기·삭제는 세로 한 열입니다.
- 이동·회전 도구를 선택하면 복사 모드·축 고정·높이 고정·수치 입력·확인·취소 조작 바로 전환합니다. 이동 수치는 mm, 회전은 도 단위입니다. 이미 객체를 잡은 상태에서 입력한 뒤 Enter로 확정합니다.
- 기존 편집 명령과 미리보기·확정 경로를 연결했습니다. 그림자 Cast/Receive는 선택 전체에 적용하며 Undo로 복원합니다.
- 객체 이름은 표시할 선택 항목에 한해 읽고 캐시합니다. 바와 팝업도 상태가 바뀔 때만 다시 그립니다. 이동·회전 수치 변경은 숫자 영역만 복구·갱신하며 전체 래스터 기준과 픽셀이 일치합니다. 아이콘 호버는 모델 재그리기나 선택·편집 기록을 만들지 않습니다.
- 기존 오른쪽 사용자 HUD를 유지합니다. 패스 버튼을 하단 묶음으로 이동하면서 내보내기 호버 숨김 조건까지 적용되던 문제를 수정했습니다. 같은 위치에서 HUD가 숨겨지거나 GL 화면에 가려져도 복구합니다. 작은 창에서는 객체 바가 오른쪽 HUD를 가리지 않도록 하단 공간을 확보합니다.
- 모든 새 HUD는 메인 뷰어의 자식 창입니다. 로딩·숨김·창 종료를 따르며 재질 HUD와 객체 바를 겹쳐 표시하지 않습니다.

검증: 100%·150% 배율, 팝업 위치·세로 편집 목록·스크롤·창 크기 변경·로딩 숨김/복구·기존 오른쪽 HUD 복구를 확인했습니다. 실제 App 입력과 OpenGL 문맥에서 mm 이동·각도 회전·복사 이동·그림자 설정·복사/붙여넣기·그룹과 Undo/Redo가 통과했고 GL 오류는 0입니다. 재질 HUD와 중앙 단축키·Z 화각 검사도 통과했습니다.
성능 검사는 600,001개 노드를 가진 검증 그래프의 HUD 갱신만 측정합니다. 전체 모델 렌더링 성능을 측정한 수치가 아닙니다. 변경 없는 1,000회 갱신에서 선택 목록 재구성·HUD 재래스터화는 0회입니다.

버전은 1.28 유지입니다. 이미 1.28이면 새 EXE로 교체하고 기존 뷰어를 닫은 뒤 다시 실행해주세요. 1.28 미만은 설정 → 업데이트를 이용합니다.
