ToothFairy Viewer 1.28 수정본 — 곡면 UV·선택 표시·조작 비용

- UV 창에 클릭 가능한 확인 Enter / 취소 Esc 버튼을 추가했습니다. 확인은 입력 중인 숫자를 적용한 후 UV 편집을 확정하며, 취소는 입력 중인 숫자를 버리고 전체 시작 UV로 복원합니다.
- 평면에서만 이어 선택하던 조건을 제거했습니다. 같은 인스턴스·앞뒷면·재질의 숨김/소프트 경계로 연결된 곡면은 전체 표면으로 선택합니다. 원통·구면과 입체 여러 면을 검사했으며, 보이는 하드 경계와 다른 재질/인스턴스는 넘지 않습니다.
- 원본 면별 UVQ를 유지하고 UV 좌표에만 변환을 적용합니다. 비정상적으로 기울어진 UV 때문에 핸들이 선으로 무너지는 경우를 막고, 선택 전체를 포함하는 안정적인 조작 영역을 사용합니다.
- 여러 면을 선택하면 각 면의 경계를 표시합니다. 내부 삼각형 경계는 제거하고, 선택 전체를 공통 조절 영역에 포함합니다. 카메라 회전은 UV 데이터나 선택을 바꾸지 않습니다.
- 재질 바는 창 하단에 고정했습니다. 전체화면/일반 창, 오른쪽 HUD, 메뉴 길이, 화면 여백 때문에 가운데로 올라가지 않습니다. 팝업은 바 바로 위에 유지됩니다.
- UV 이동 중 파트 전체를 확장·재인덱싱·재업로드하던 경로를 제거했습니다. 선택한 좌표의 캐시를 재사용하고 UV 전용 GPU 버퍼만 갱신합니다. 위치·법선·면 인덱스·지오메트리·내비게이션 캐시를 유지합니다.
- 많은 선택 면의 표시도 동일 파트/인스턴스별로 합쳐 처리합니다. 원본·텍스처·재질·그림자·선 패스의 결과를 전체 재업로드 방식과 비교했습니다. 패킹된 좌표가 갈라져야 하는 특수 편집은 정확한 전체 갱신으로 처리합니다.
- 실제 Koki 파일의 곡면 20,098면·95,256개 좌표에서 UV 변경은 CPU 중앙값 5.70ms, GPU 완료 포함 5.94ms였습니다. 첫 곡면 선택은 약 98ms입니다. 이 수치는 UV 변경 작업 시간이며 전체 뷰포트 FPS를 뜻하지 않습니다.
- 원통/구면의 최상위 원본 및 공유 컴포넌트 저장·재열기·실행 취소/다시 실행, 원본 이미지 보존, 실제 App 조작, 100/125/150/200% 배율 버튼·하단 위치와 내보내기 결과를 검사했습니다.

버전은 1.28 유지입니다. 이미 1.28이면 새 EXE로 교체하고 기존 뷰어를 닫은 뒤 다시 실행해주세요. 1.28 미만은 설정 → 업데이트를 이용합니다.
