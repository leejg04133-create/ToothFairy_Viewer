ToothFairy Viewer 1.28 수정본 — 새 재질 / UV 조작 / 동적 구성요소

- 하단 재질 바에 + 재질을 추가했습니다. 기존 메뉴와 같은 새 재질 생성 동작을 사용하며 스포이드로 선택한 재질과 연결을 끊고 독립된 재질로 칠합니다. 새 재질을 만드는 동안 기존 면의 색을 바꾸지 않습니다.
- UV 조작 중 Alt를 누르거나 떼면 즉시 중심 대칭 확대/축소와 반대편 고정 사이를 전환합니다. Shift는 비율 유지·이동축 고정·15도 회전 스냅, Shift+Alt는 중심과 비율을 함께 유지합니다. 중앙을 넘어 드래그하는 UV 뒤집기도 검사했습니다.
- UV 수치가 바뀔 때 동일한 하단 바를 다시 그리던 작업을 제거했습니다. 투명 텍스처의 UV만 바꿀 때 호환되는 그림자 구조를 재사용하며, 반사 UV를 갱신할 때 같은 이미지와 전체 속성 아틀라스를 다시 준비하지 않습니다.
- 반대 방향의 값 범위(예: 0→90과 0→-45)를 가진 동적 구성요소를 다중 선택하여 잡을 때 한쪽이 멈추거나 반대로 따라가던 문제를 수정했습니다. 각 객체의 설정 방향을 유지한 같은 진행량으로 조작합니다.
- 동적 동작으로 숨겨진 선택 객체도 연결을 유지합니다. 수동 숨김은 구분합니다. 선택 작업을 끝내거나 원복할 때 다른 객체의 독립 재생을 멈추던 문제도 수정했습니다.
- 우클릭 더블클릭의 선택 전체 초기값 복원, 움직이거나 숨겨져 두 번째 클릭이 빗나가는 경우, 캡처 해제, 드래그 취소·Undo·Redo를 검사했습니다. SDK로 작성한 SKP의 문 회전·숨김 대체 구성·복사본 연결도 검사했습니다.

검증: 100%/150% UI, 실제 App 키·마우스 입력, 원본 해상도의 2048px PNG 교체 후 24회 UV 변경, 반사 UVQ, 내보내기 5개 패스의 전체 재업로드 기준 이미지 비교, 기존 공통 편집 기록 검사가 통과했습니다. 성능 측정은 작은 검증 모델의 UV 갱신 CPU+GPU 시간이며, 대형 장면 전체 렌더링의 무렉 보장은 아닙니다. 이전 수정의 대형 그림자 화면 갱신과 반복 주변 균열 가공 비용은 남아 있습니다.

버전은 1.28 유지입니다. 이미 1.28이면 새 EXE로 교체하고 기존 뷰어를 닫은 뒤 다시 실행해주세요. 1.28 미만은 설정 → 업데이트를 이용합니다.
