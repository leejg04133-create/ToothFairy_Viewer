ToothFairy Viewer 1.28 수정본 — UV 직접 선택·조작 수정

- UV 버튼을 누르면 슬라이더가 바로 열리고, 면을 클릭하면 즉시 파란 이동·회전·크기 조절 핸들이 표시됩니다. 별도의 첫 Enter로 편집을 시작하던 단계를 제거했습니다.
- Enter는 현재 UV 편집 최종 확정, Esc는 전체 변경 취소입니다. 숫자 입력 중 Enter는 해당 숫자 입력만 완료합니다. 키 반복이나 프레임 폴링으로 두 단계가 연속 실행되지 않도록 검사했습니다.
- 선택 해제를 우클릭으로 옮겼습니다. 휠클릭은 UV 선택/편집 중에도 화면 회전이며 Shift+휠클릭은 화면 이동입니다.
- UV 선택은 점박이 메시 선택 표시 대신 연속된 옅은 파란 표시와 파란 조절 핸들을 사용합니다.
- 그룹이 없는 최상위 원본 면도 메쉬 단계 없이 직접 고를 수 있습니다. UV 선택에서만 최상위 면 제외 조건을 해제했으며 일반 오브젝트 선택 동작은 유지합니다.
- 한 SketchUp 면을 구성하는 내부 삼각형을 함께 선택합니다. 같은 평면·같은 재질에서 숨김/소프트 대각선으로 이어진 면도 닫힌 표면 단위로 선택하고 해제합니다. 보이는 경계, 다른 재질, 반대쪽 면과 다른 인스턴스로는 넘어가지 않습니다.
- 최상위 원본 면의 UV 저장·실행 취소·재저장 및 기존 재질 변경 후 UV 저장을 검사했습니다. 구성요소의 다른 복사본과 앞뒷면, 원본 폴리곤과 숨김 대각선 연결도 유지합니다.
- 실제 App 마우스/키 입력과 GL 화면에서 핸들 표시·휠클릭 회전·우클릭 해제·단일 Enter 확정·Esc 복원을 100/125/150/200% 배율로 검사했습니다. 별도 SDK/GPU 검사로 저장·재열기, 내보내기, RGB/UV 연속 실행 취소도 확인했습니다.
- 기존 텍스처 이미지·이름 표시, 색상·기본값 복원, 투명도 전용 처리와 UV/표면 간격 통일은 유지합니다.

버전은 1.28 유지입니다. 이미 1.28이면 새 EXE로 교체한 뒤 기존 뷰어를 닫고 다시 실행해주세요. 1.28 미만은 설정 → 업데이트를 이용합니다.
