ToothFairy Viewer 1.28 수정본 — 텍스처 표시·색상 복원·UV 직접 편집

- 텍스처를 스포이드로 고르면 실제 이미지 미리보기와 텍스처 이름을 표시합니다. 원본 파일명이 없는 재질은 재질 이름을 표시합니다.
- UV와 표면은 같은 크기의 흰색 선 아이콘과 같은 글자 간격을 사용합니다. 표면 테두리·삼각 표시와 중복 새로고침을 제거했습니다. 색상은 왼쪽 휠·오른쪽 H/S/B의 가로 배치를 유지합니다.
- 표면 팝업은 표면 버튼 위에 열리며 좌측 초기화는 표면 값만 초기화합니다. 색상 초기화는 색상 팝업에 있습니다.
- UV: 메쉬 단계 진입 없이 면 선택 → Enter → 파란 이동·회전·크기 조절 핸들 또는 U/V·회전·배율 슬라이더로 조절합니다. 선택 중 휠클릭은 해당 면 해제, Enter는 선택 확인/편집 완료, Esc는 전체 편집 취소입니다.
- 선택한 면·인스턴스·앞뒷면을 구분합니다. 초기화·취소는 전체 시작 UV를 복원하며, 색상과 UV를 연속으로 실행 취소/다시 실행해도 공유 인스턴스와 재질 상태를 유지합니다. 저장·재열기와 내보내기도 검사했습니다.
- 텍스처에 재질 RGB를 다시 곱하던 오류, 투명도 조절이 RGB나 면별 표면 값을 덮어쓰던 오류, 숫자 RGB만 복구해 원래 텍스처가 돌아오지 않던 오류를 수정했습니다.
- SDK 원본 이미지·유효 색상 이미지·재질 RGB·렌더링 정점 색을 분리했습니다. 원본 색조 변환 방식을 유지하며 현재 이미지, 불투명도, UV, 표면 값을 보존합니다.
- 동일 원본의 SDK 작업용 텍스처와 재질을 재사용합니다. 파생 이미지 캐시는 제한하고, SDK 종료 전에 작업 리소스를 해제합니다. 색 변경은 대상 이미지와 색 버퍼만 갱신하며 지오메트리·내비게이션 캐시를 유지합니다.
- 실제 SDK 색상·원복·불투명도·실행 취소, 공유 컴포넌트 앞뒷면 저장, UV 내보내기, 키 입력, 100/125/150/200% 배율과 대형 Koki 모델을 검사했습니다. Koki 시간은 SDK 색상 계산과 GPU 완료를 포함한 재질 변경 시간이며 화면 조작 FPS를 뜻하지 않습니다.

버전은 1.28 유지입니다. 이미 1.28인 경우 새 EXE로 교체하고 실행 중인 뷰어를 닫은 뒤 새 파일을 실행하세요. 1.28 미만은 설정 → 업데이트를 이용합니다.
