ToothFairy Viewer 1.29 — 미니 HUD·메뉴 정리·원본 선 표시·준비 안내

- 설정의 단축키를 폴더 버튼들 아래로 이동했습니다. 이어서 조작 속도 → 프록시 → 그림자 프록시 → 다크모드 순서입니다. 기존 프록시 단계 0·25·75·100과 저장값, 사용자 HUD 연결을 유지합니다.
- 지평선 맞추기·2점 투시는 편집에서 카메라의 화각 아래로 이동했습니다. 기존 동작·단축키/HUD ID를 유지합니다.
- 재질과 선택 객체 미니 HUD는 3초간 입력이 없으면 부드럽게 숨고, 다시 조작하면 사라지던 지점에서 부드럽게 복구합니다. 공통 등록 경로를 추가해 이후 미니 HUD도 같은 규칙을 사용합니다. 페이드는 보관된 네이티브 비트맵을 재사용하며 3D 장면이나 HUD 글자를 다시 계산하지 않습니다.
- Space도 Esc와 같이 미니 HUD를 닫습니다. 재질 HUD에서 객체를 선택하면 선택 객체 HUD로 전환합니다. 재질 바의 Esc 글자를 없애고 X 버튼 공간을 넓혔으며 불투명도 슬라이드를 조금 줄였습니다.
- 다크모드 OFF에서 재질·선택 객체 미니 HUD와 색상·표면·UV·선택 팝업도 밝은 테마로 표시됩니다. 테마 변경 시 캐시도 갱신합니다.
- 선택 목록의 아이콘 잘림과 마지막 행 여백을 수정했습니다. 원시 메시와 메시로 만든 그룹도 선택 HUD를 표시하며, 그룹 내부에서는 HUD가 유지되고 그룹 들어가기 버튼이 그룹 나가기로 바뀝니다.
- 숨기기·단독 보기를 역방향 토글로 사용할 수 있고 아이콘도 상태에 맞게 바뀝니다. 기존에 숨겨둔 다른 객체와 동적 구성요소의 숨김을 임의 복구하지 않습니다. 동일 객체 선택은 추가로 선택할 수 있는 대상이 있을 때만 활성화됩니다.
- 이동·회전의 축 버튼을 누르면 마우스로 먼저 잡지 않아도 수치를 입력해 Enter로 확정할 수 있습니다. 방향키 외에 X·Y·Z도 지원합니다. 단축키 설정의 ‘이동·회전 X축/Y축/Z축’을 변경하면 표시와 실제 입력이 함께 바뀝니다. 일반 상태의 Z 화각은 유지합니다.
- 이동·회전의 수동 Z 잠금은 도구 전환과 확정·취소 후에도 유지하고 저장합니다.
- 하단 내보내기를 원래 메뉴와 같은 크기의 아이콘·이름 버튼으로 복구했습니다. 서브메뉴가 아래 사용자 HUD 공간을 침범하지 않도록 캐시와 높이 계산을 수정했습니다. 레이어 도움말도 서브메뉴 위에 표시됩니다.
- ‘빌런탑 무기 모음 (1).skp’의 칼 표면에 나타나던 불필요한 선을 재현하고 수정했습니다. 연결 면의 앞뒤 방향이 서로 다른 Soft 선을 외곽선으로 잘못 분류한 문제였습니다. 원본 Soft/Smooth·숨김 값과 면·재질·텍스처·선 두께는 변경하지 않습니다. 로더의 외곽선 인접 방향만 맞추며 매 프레임 재계산하지 않습니다. 기존 SDK도 원본 루프를 읽어 같은 판정을 합니다.
- 무거운 조명·태양·캐릭터·크랙·파괴 준비 중에는 더 둥근 안내창과 파도처럼 움직이는 점 세 개를 표시합니다. 짧은 작업에는 표시하지 않습니다. 준비창은 별도 UI 스레드에서 움직이며, 완료하면 닫힙니다. 기존 SKP Live2D 로딩 화면은 유지합니다.

검증: 100%·150% 배율의 네이티브 미니 HUD/메뉴/재질 검사, 실제 App+OpenGL 입력으로 이동·회전 수치/복사/숨김·단독 보기/그룹/Undo·Redo/Z 화각 검사가 통과했습니다. 페이드에서 재래스터화가 없고 수치 부분 갱신은 전체 래스터와 픽셀이 일치합니다. 실제 무기 파일의 같은 시점에서 수정 전후 이미지를 비교했으며, 반대 방향 면으로 만든 SDK 회귀 모델과 구형 SDK 루프 호환 경로도 통과했습니다. 작업 스레드가 멈춘 동안에도 점 애니메이션은 움직이고 완료 후 닫히는 것을 검사했습니다.
성능 수치는 HUD 검사에 한정합니다. 모든 PC에서 전체 모델이 무렉이라고 검증한 것은 아닙니다.
