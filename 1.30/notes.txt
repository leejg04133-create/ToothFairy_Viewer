- 이동·회전 도중 수치 칸이나 축 버튼을 먼저 누르지 않아도 숫자를 입력하면 바로 수치 입력으로 전환합니다. 숫자 키가 패스 전환 단축키로 먼저 처리되던 연결을 수정했습니다.
- 소수점·부호와 숫자 키패드를 지원합니다. 입력 중에는 마우스 움직임이 미리보기를 덮어쓰지 않고, 마우스 버튼을 놓아도 미확정 상태를 먼저 완료하지 않습니다. Enter로 정확한 값을 한 번 확정하며 이동·회전 도구는 유지합니다. 기존 Esc·연속 확정·Undo/Redo는 유지합니다.
- 캐릭터 추가 버튼의 최초 남성·여성 모델 데이터 읽기, 배치 전 준비, 흩뿌리기 준비와 형상 재생성도 공통 준비 안내에 연결했습니다. 실제 생성·조명·태양·크랙·파괴와 기존 SKP 로딩 연결도 유지합니다.
- 준비 안내는 실제 작업이 0.2초 이상 지속할 때만 표시됩니다. 빠른 작업을 일부러 지연시키지 않습니다. 별도 GDI+ UI 스레드에서 점 세 개가 파도처럼 움직이며 작업이 끝나면 닫힙니다.

검증: 실제 App 키/문자/마우스 입력과 OpenGL 문맥에서 이동·회전 미리보기 중 직접 숫자 입력, 소수·음수·키패드 문자 경로, 패스 전환 방지, 입력 중 마우스 이동·버튼 해제, Enter 한 번 확정과 Undo를 확인했습니다. 실제 내장 캐릭터 리소스를 읽고 첫 캐릭터를 생성·GPU에 추가하는 검사도 통과했습니다. 검증용 작은 장면에서는 초기 데이터 읽기 약 17ms, 첫 생성 약 7ms여서 안내창이 뜨지 않았습니다. 이 수치를 큰 SKP의 전체 작업 시간으로 일반화하지 않습니다. 별도 느린 작업 검사에서는 주 스레드가 대기 중에도 안내창이 표시·애니메이션되고 완료 후 닫혔습니다. 100%·150% UI 및 기존 중앙 단축키 검사, GL 오류 0을 확인했습니다.

버전은 1.29 유지입니다. 기존 실행창을 닫고 같은 경로의 새 EXE를 실행해주세요.

ToothFairy Viewer 1.29 수정본 — 이동·회전 연속 작업 / 미니 HUD 종료

- 이동·회전 수치 Enter는 현재 한 단계만 확정합니다. 같은 도구·축·수동 복사 모드와 조작 바를 유지해 연속 작업할 수 있습니다. 각 단계는 각각 Undo/Redo됩니다.
- 유지된 도구에서 Enter를 다시 누르면 다음 수치를 입력할 수 있습니다. Enter를 길게 누른 반복 입력으로 뜻하지 않은 추가 단계가 확정되지 않습니다.
- 이동·회전에서 Esc를 누르면 입력 중이더라도 도구를 종료하고 선택 객체 미니 HUD로 돌아갑니다. 이미 확정한 변경은 유지하고 미확정 미리보기만 취소합니다. 조작 바의 체크 버튼은 명시적인 도구 완료 버튼으로 유지합니다.
- 3초 무입력 자동 숨김은 투명도만 0으로 남기는 방식에서 실제 종료로 변경했습니다. 사라지는 도중의 조작은 종료를 취소하고, 완전히 닫힌 뒤에는 일반 마우스 이동만으로 재등장하지 않습니다. 이동·회전, Paint, 스포이드와 미확정 UV 상태도 정리합니다. 이미 확정한 편집은 되돌리지 않습니다.
- 종료 후 M/Q로 이동·회전을 다시 선택하면 미니 HUD가 정상적으로 열립니다. 버전 번호는 1.29를 유지합니다.

검증: 실제 App 입력·OpenGL 문맥에서 이동/회전 각각 3회 연속 확정, 단계별 Undo/Redo, Esc 복귀, 자동 종료 시 미확정 미리보기 복구, M/Q 재시작, 연속 복사, Enter 반복 입력 방지와 GL 오류 0을 확인했습니다. 100%·150% UI 배율, 미확정 UV 취소, 재질/중앙 단축키 회귀 검사도 통과했습니다.
이미 1.29를 실행 중이면 기존 창을 닫고 같은 경로의 새 EXE를 실행해주세요. 같은 버전은 버전 비교 방식의 자동 업데이트 목록에 새 버전으로 표시되지 않습니다.

--- 이전 1.29 변경 사항 ---

ToothFairy Viewer 1.29 — 미니 HUD·메뉴 정리·원본 선 표시·준비 안내

- 설정의 단축키를 폴더 버튼들 아래로 이동했습니다. 이어서 조작 속도 → 프록시 → 그림자 프록시 → 다크모드 순서입니다. 기존 프록시 단계 0·25·75·100과 저장값, 사용자 HUD 연결을 유지합니다.
- 지평선 맞추기·2점 투시는 편집에서 카메라의 화각 아래로 이동했습니다. 기존 동작·단축키/HUD ID를 유지합니다.
- 재질과 선택 객체 미니 HUD는 3초간 입력이 없으면 부드럽게 사라진 뒤 실제 종료됩니다. 도중에 입력하면 종료 시간을 다시 세고 페이드를 되돌립니다. 완전히 종료된 후에는 단순 마우스 움직임으로 다시 나타나지 않습니다. 도구를 다시 선택하거나 새로운 객체를 선택하면 새로 열립니다. 페이드는 보관된 네이티브 비트맵을 재사용하며 3D 장면이나 글자를 다시 계산하지 않습니다.
- Space도 Esc와 같이 미니 HUD를 닫습니다. 재질 HUD에서 객체를 선택하면 선택 객체 HUD로 전환합니다. 재질 바의 Esc 글자를 없애고 X 버튼 공간을 넓혔으며 불투명도 슬라이드를 조금 줄였습니다.
- 다크모드 OFF에서 재질·선택 객체 미니 HUD와 색상·표면·UV·선택 팝업도 밝은 테마로 표시됩니다. 테마 변경 시 캐시도 갱신합니다.
- 선택 목록의 아이콘 잘림과 마지막 행 여백을 수정했습니다. 원시 메시와 메시로 만든 그룹도 선택 HUD를 표시하며, 그룹 내부에서는 HUD가 유지되고 그룹 들어가기 버튼이 그룹 나가기로 바뀝니다.
- 숨기기·단독 보기를 역방향 토글로 사용할 수 있고 아이콘도 상태에 맞게 바뀝니다. 기존에 숨겨둔 다른 객체와 동적 구성요소의 숨김을 임의 복구하지 않습니다. 동일 객체 선택은 추가로 선택할 수 있는 대상이 있을 때만 활성화됩니다.
- 이동·회전의 축 버튼을 누르면 마우스로 먼저 잡지 않아도 수치를 입력해 Enter로 확정할 수 있습니다. 방향키 외에 X·Y·Z도 지원합니다. 단축키 설정의 ‘이동·회전 X축/Y축/Z축’을 변경하면 표시와 실제 입력이 함께 바뀝니다. 일반 상태의 Z 화각은 유지합니다.
- 이동·회전의 수동 Z 잠금은 도구 전환과 확정·취소 후에도 유지하고 저장합니다.
- 하단 내보내기를 원래 메뉴와 같은 크기의 아이콘·이름 버튼으로 복구했습니다. 서브메뉴가 아래 사용자 HUD 공간을 침범하지 않도록 캐시와 높이 계산을 수정했습니다. 레이어 도움말도 서브메뉴 위에 표시됩니다.
- ‘빌런탑 무기 모음 (1).skp’의 칼 표면에 나타나던 불필요한 선을 재현하고 수정했습니다. 연결 면의 앞뒤 방향이 서로 다른 Soft 선을 외곽선으로 잘못 분류한 문제였습니다. 원본 Soft/Smooth·숨김 값과 면·재질·텍스처·선 두께는 변경하지 않습니다. 로더의 외곽선 인접 방향만 맞추며 매 프레임 재계산하지 않습니다. 기존 SDK도 원본 루프를 읽어 같은 판정을 합니다.
- 무거운 조명·태양·캐릭터·크랙·파괴 준비 중에는 더 둥근 안내창과 파도처럼 움직이는 점 세 개를 표시합니다. 짧은 작업에는 표시하지 않습니다. 준비창은 별도 UI 스레드에서 움직이며, 완료하면 닫힙니다. 기존 SKP Live2D 로딩 화면은 유지합니다.

검증: 100%·150% 배율의 네이티브 미니 HUD/메뉴/재질 검사, 실제 App+OpenGL 입력으로 이동·회전 수치/복사/숨김·단독 보기/그룹/Undo·Redo/Z 화각 검사가 통과했습니다. 페이드에서 재래스터화가 없고 수치 부분 갱신은 전체 래스터와 픽셀이 일치합니다. 실제 무기 파일의 같은 시점에서 수정 전후 이미지를 비교했으며, 반대 방향 면으로 만든 SDK 회귀 모델과 구형 SDK 루프 호환 경로도 통과했습니다. 작업 스레드가 멈춘 동안에도 점 애니메이션은 움직이고 완료 후 닫히는 것을 검사했습니다.
성능 수치는 HUD 검사에 한정합니다. 모든 PC에서 전체 모델이 무렉이라고 검증한 것은 아닙니다.
