1.40 수정: 파괴 후 남는 막·관통 형상

- 실제 Forgotten Temple 저장 작업의 기둥과 기존 파괴 이력을 복사해 재현했습니다. 열린 자식 면 하나 때문에 정상 입체까지 면 압출로 계산되면서, 깊이를 넘겨도 막과 길게 늘어진 면이 생기던 경로를 수정했습니다.
- 연결된 입체와 실제 열린 장식 면을 구분하고, 계산에 필요한 평면 끝막이는 화면·내보내기에 새 면으로 추가하지 않습니다. 열린 장식 면과 기존 내부 면도 같은 절단 부피 안에서만 정리합니다.
- 같은 그룹에 합쳐진 파괴 결과를 다시 자르는 경우도 검사했습니다. 기존 면의 재질·색·UV와 파괴 깊이의 감소 형태는 유지합니다.
- 실제 저장 작업에서 동일한 100cm·200cm 깊이, 첫 파괴·재파괴를 검사했습니다. 얕은 깊이에서 남아야 할 내부는 유지하고, 깊이가 벽을 넘는 부분은 관통됩니다. 이전 소스의 동일 200cm 결과와도 비교했습니다.
- 기존에 저장된 파괴 형상은 자동으로 덮어쓰지 않습니다. 기존 레이어에서 원하는 깊이를 입력한 뒤 완료로 다시 계산해 주세요.
- 버전은 같은 1.40입니다. 이미 1.40 사용 중이면 새 EXE로 교체해 주세요.

1.40 수정: 파괴 백페이스 컬링·최대 깊이 입력·숨긴 선택 가이드

- 파괴 마스크 버튼을 백페이스 컬링으로 변경했습니다. 그릴 때의 면 방향을 기준으로 뒷면을 제외하며, 앞에 다른 면이 있다는 이유만으로 같은 방향의 면을 제외하지 않습니다. 미러 인스턴스도 같은 방향 규칙을 따릅니다.
- 최대 깊이 숫자 입력의 100cm 상한을 제거했습니다. 200cm와 1250cm Enter 입력을 실제 HUD에서 확인했습니다. 슬라이더의 기본 조절 구간과 숫자 입력 범위는 구분합니다.
- 백페이스 컬링과 깊이 계산을 분리하고 뒷벽 보호를 강제로 켜던 연결을 제거했습니다. 닫힌 벽과 양면 재질 벽에서 얕은 파괴는 안쪽을 남기고, 깊이가 벽 두께를 넘으면 캡 없이 관통되는 것을 검사했습니다.
- 마스크를 그릴 때 추가 깊이 버퍼 생성과 가장 앞면 계산을 하지 않습니다. 기존 공간 후보 검색·비동기 파괴 계산·마스크 유지 흐름은 보존합니다.
- 파괴 레이어의 눈을 끄면 선택 자체는 유지하면서 파란 선택 박스와 방향 기즈모를 숨깁니다. 다시 켜면 선택 박스를 복원합니다. 다른 선택 오브젝트에는 영향을 주지 않습니다.
- 저장 형식 5는 이전 형식 2·3·4 읽기를 유지합니다. 이전 브러시 필드 정렬과 새 컬링 설정 저장·복원, 전체 작업 저장·재열기 검사를 실행했습니다. 원본 SKP는 변경하지 않습니다.
