1.41 수정본: 현재 작업 자동 저장 후 업데이트 적용

- 원본 SKP의 수정 표시만 보고 업데이트를 차단하던 조건을 제거했습니다. 업데이트 적용을 확인하면 현재 뷰어 작업을 자동 저장하고, 저장 완료 후 업데이트 및 같은 SKP 재열기를 시작합니다.
- 원본 SKP를 덮어쓰지 않습니다. 뷰어 작업 저장소를 사용하므로 조명·재질·크랙·파괴·캐릭터 등의 작업을 기존 복원 방식으로 이어갑니다.
- 작업 저장이 실패하면 업데이트 실행 파일 교체를 시작하지 않고 현재 작업과 창을 유지합니다. 이미 요청된 저장의 오류와 새 저장 요청 실패도 확인합니다.
- 업데이트 실행 실패 시에도 저장한 작업과 현재 창을 유지합니다. 실행 성공 시 종료 과정에서 같은 작업을 두 번 저장하지 않습니다.
- 실제 SKP로 저장 완료 전 업데이트가 실행되지 않는지, 저장 실패와 설치 실행 실패 시 작업 보존, 변경된 값 복원 및 원본 SKP 미변경을 검증했습니다.

이전 1.41 수정 내용:
1.41: 시작 대기 응답 개선 · 고배율 팔레트 크기 수정

- 그래픽 초기화 중 작업 완료를 기다리는 동안에도 창 메시지를 처리하도록 수정했습니다. 보조 작업이 창 응답을 기다릴 때 서로 멈출 수 있는 대기를 재현하고 검사했습니다.
- 셰이더 준비와 최초 캐시 생성 중에도 창 메시지를 처리합니다. 시작 진행 표시를 실제 준비 단계에 맞춰 갱신하고, 느린 셰이더 게시 구간을 로그에 기록합니다.
- 셰이더 보조 프로세스의 읽기·쓰기 요청에 시간 제한을 적용했습니다. 보조 프로세스가 응답하지 않아 무한 대기하는 경우를 방지하며, 같은 셰이더 소스로 다시 준비합니다.
- 이빨요정 Live2D 로딩을 유지합니다. 로딩 준비 대기는 메시지가 계속 들어오는 경우에도 설정한 제한 시간을 지킵니다.
- 팔레트만 배율과 관계없이 고정 픽셀 크기로 그리던 부분을 수정했습니다. 메뉴와 같은 UI 배율로 원·글자를 함께 확대하며, 클릭·호버도 같은 좌표 변환을 사용합니다. 오버레이 창과 카메라 입력은 실제 픽셀 크기를 유지합니다.
- 시작/최근 작업/SKP 열기/이미지 열기/종료, 최초·캐시 재사용 시작의 창 응답, 100·125·150·200% 팔레트, GPU 마스크, 동적 문 저장·복원 검사를 수행했습니다.

렌더링 색상·투명도·그림자 품질 및 저장 작업 형식은 변경하지 않았습니다.
