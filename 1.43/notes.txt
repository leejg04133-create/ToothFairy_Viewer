1.43: 저장된 동적 문을 다시 조작할 때 각도가 추가되는 문제 수정

- 저장 작업 복원 뒤 SketchUp 동적 목록이 늦게 갱신되면, 열린 문 자세를 새 기준 0도로 등록해 다음 동작에서 각도가 추가되던 경로를 수정했습니다.
- 같은 동적 채널의 기준 자세·기준 값·현재 값을 유지합니다. 일반 이동·회전으로 배치한 위치도 유지하며, 클릭 대상과 목록 메타데이터만 다시 연결합니다.
- 플러그인 목록에 없는 뷰어 복사 구성요소와 동적 숨김 전환도 기존 동작 상태를 유지합니다. 채널 순서가 달라져도 Undo/Redo가 자세와 동작 값을 함께 복원합니다.
- 실제 small dungeon.skp의 두 문으로 수정 전 실패를 재현했습니다. 수정 후 저장·새 런타임에서 복원·늦은 동적 목록 갱신·닫기와 반복 열기/초기화, 목록 순서 변경 뒤 Undo/Redo를 검사했습니다.
- 네이티브 속성 연결, 복사 구성요소 동시 동작, 숨김 대체 부품, 그랩 회전/이동·복합 축·DPI, 우클릭 두 번 초기화와 업데이트 자동 저장 검사를 통과했습니다.
- 1.42의 자동 저장 후 업데이트, 시작 응답 개선, 고배율 팔레트 수정도 포함합니다. 원본 SKP와 작업 저장 형식은 변경하지 않습니다.
