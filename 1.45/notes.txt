1.45: 삭제 병목 개선

- 캐릭터 삭제 시 전체 공간 검색 구조와 배경 메시 캐시를 다시 만들지 않습니다. HUD에서 삭제할 때 불필요했던 캐릭터 데이터 복사도 제거했습니다.
- 파괴 레이어 삭제·실행 취소·다시 실행은 변경된 GPU 부품만 복원·해제합니다. 조각이 사라지거나 복구될 때도 무관한 배경 부품 목록을 옮기지 않습니다.
- 레이어 삭제의 전체 상태 중복 적용과 기록용 메모리 재할당을 줄였습니다. 조명 삭제의 중복 설정/카메라 기록 복사를 제거했습니다.
- 조명·장면 삭제는 전체 메시 재업로드가 없는 것을 검증했습니다. 삭제 구간별 성능 로그를 추가했습니다.
- Koki 604,554개 노드·15,387개 부품 모델에서 캐릭터 삭제 후 공간 검색 전체 재생성 1회→0회, 파괴 복원 부품 순회 15,387개→변경 부품 1개를 확인했습니다. 조각 GPU 슬롯 삭제·복구와 다섯 종류의 Undo/Redo도 검증했습니다.
- GPU 출력의 전체 업로드 기준 비교, 일반 편집/크랙 기록, 동적 문 복원, 업데이트 자동 저장 검사를 통과했습니다. 그림자 농도·재질·텍스처·선 두께·내보내기 품질은 변경하지 않았습니다.
