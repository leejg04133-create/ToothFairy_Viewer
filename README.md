# ToothFairy Viewer

현재 배포 버전: **1.21**

SKP 로딩의 자동 조명 사전 계산을 제거하고, 같은 원본을 다시 열 때 검증된 상속 UV를 재사용합니다. 텍스처·그림자·선·불투명도·내보내기 품질은 유지합니다. 예기치 않은 종료 진단을 강화했으며, 보고된 종료 현상은 로컬에서 재현되지 않았습니다.

- [실행 파일](1.21/SkpViewportViewer.exe)
- [변경 내역 및 측정 조건](1.21/notes.txt)
- [검증 기록](1.21/validation.json)
- [업데이트 정보](latest.json)

이전 버전에서 설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.21 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

280MB 원본 숙소 파일에서 읽기·변환 53.03초 → 재실행 37.45초를 확인했습니다. 최초 실행은 기존 SDK 계산을 수행하며, 자동 조명 준비 제거 효과는 별도입니다. 전체 정점 위치·UV·면 방향·색상·텍스처 RGBA 검증값이 일치합니다. 실제 열기와 조작 검사, SDK 저장/재열기, MSAA 2배 4K 검정 화면 회귀 검사를 통과했습니다. PC와 파일에 따라 소요 시간은 달라집니다.
