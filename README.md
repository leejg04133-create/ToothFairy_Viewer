# ToothFairy Viewer

현재 배포 버전: **1.19**

Shift+Tab 입력 중복과 왼쪽 메뉴의 오른쪽 화면 잔상을 수정했습니다. 한 번의 Tab 누름은 키를 뗄 때까지 한쪽 메뉴만 조작하며, 새 화면과 메뉴 위치를 함께 반영합니다.

그림자 방향 고정 상태의 위치 매칭 검색 병목을 수정한 1.19입니다. 야구장 실제 파일/저장 설정/두 시점에서 전체 GPU 프레임 약 1.6~1.9초→44~56ms, 이미지 픽셀 차이 0을 확인했습니다. 상세 조건과 테스트 기록은 validation.json에 있습니다.

- 실행 파일: [1.19/SkpViewportViewer.exe](1.19/SkpViewportViewer.exe)
- 변경 내역: [1.19/notes.txt](1.19/notes.txt)
- 검증 기록: [1.19/validation.json](1.19/validation.json)
- 자동 업데이트: [latest.json](latest.json)

왼쪽 아래 카메라 패드의 세로·가로 핸들과 조이스틱을 끌어 조작합니다. 손을 놓으면 중앙으로 복귀합니다. 세 아이콘 위에서 휠을 돌리거나 아이콘을 클릭하면 회전 → 롤/화각 → 이동 모드가 바뀝니다. 롤/화각 모드에서는 각각의 슬라이더를 사용합니다.

편집의 화면 프록시는 0 / 25 / 75 / 100 단계입니다. 25는 작은 구성요소, 75는 작은~중간 구성요소, 100은 전체 객체를 조작 중 상자로 표시합니다. 25·75에서는 조작 중 전체 텍스처 RGB를 재질 색으로 대신 표시하고, 멈추면 원본을 복원합니다. 그림자 프록시는 작은 객체의 그림자부터 제외합니다.

양쪽 메뉴 바는 고정입니다. 개별 아이콘을 길게 눌러 좌우로 이동하거나 순서를 바꿀 수 있습니다. Tab은 오른쪽/HUD, Shift+Tab은 왼쪽을 접고 펼칩니다. 화각 조절 직후 숫자와 Enter로 값을 입력할 수 있습니다. 짧은 정지 후 재조작할 때 원본 복원을 반복하지 않도록 200ms의 정착 구간을 사용합니다.

내보내기는 원래 형상·텍스처와 전체 그림자 정밀도를 사용합니다. 화면 카메라 패드는 이미지에 포함되지 않습니다.

설정 → 업데이트 확인 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 파일은 SkpViewportViewer.exe입니다. 이전 배포 폴더는 유지합니다.
