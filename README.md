- 실행 파일: [1.03/SkpViewportViewer.exe](1.03/SkpViewportViewer.exe)
- 변경 내역: [1.03/notes.txt](1.03/notes.txt)

기존 뷰어의 설정에서 업데이트 확인 → 다운로드 → 다시 시작을 진행하면 됩니다. 사용자에게 GitHub 로그인이나 토큰을 요구하지 않습니다. 수동으로 전달할 때도 `1.03/SkpViewportViewer.exe`를 사용합니다. `.update-helper.exe`는 업데이트 보조 파일입니다.

## 1.03 변경

대형 모델에서 반복하던 표시·그림자 상태 검사를 한 번의 순회로 통합했습니다. 위치 비교용 데이터를 연속 배치하고 변경이 없는 프레임의 임시 배열 생성을 제거했습니다. 직접 수정된 위치, 레이어, 숨김, 그림자 설정을 감지하는 검사는 유지합니다.

텍스처 원본 해상도, 그림자 품질, GPU 공통 처리 기준은 유지합니다. 1.02.1의 셰이더 호환성과 업데이트 보조 파일 복구 수정도 포함합니다.

실제 대형 모델의 CPU 검사 구간 개선과 렌더링 비교 81건, 객체 변경 후 탐색 결과, 업데이트 교체·재시작을 검사했습니다. GPU 그림자 병목 전체 해결이나 모든 PC에서 동일한 FPS를 보장하는 버전은 아닙니다.

## 이후 배포

새 버전 폴더에 내부 버전도 일치하는 `SkpViewportViewer.exe`를 넣고 `latest.json`의 버전·경로·크기·SHA-256·변경 내역을 함께 갱신합니다. 해당 폴더와 `latest.json`을 커밋하고 GitHub에 푸시해야 사용자에게 업데이트가 표시됩니다. 게시된 버전의 EXE를 다른 내용으로 덮어쓰지 말고 새 버전 번호를 사용합니다.
