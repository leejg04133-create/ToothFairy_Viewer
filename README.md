1.32 이하에서는 앱 업데이트를 이용하세요. 기존 작업 자동 저장은 1.32부터 적용됩니다.

뷰어를 닫거나 다른 파일을 열 때 작업을 저장하고, 같은 SKP를 다시 열면 이어갑니다. 원본 SKP는 자동으로 덮어쓰지 않습니다. 최근 목록의 삭제는 해당 뷰어 작업 데이터도 제거하며 원본 SKP는 유지합니다.

태양 설정은 그림자 메뉴 맨 아래에서 조절합니다. 라이트 메뉴는 추가한 조명의 목록과 조절에 집중합니다. 태양 상세·효과는 접어서 보관하며, 기존 조명·그림자 값과 내보내기 결과를 유지합니다.
