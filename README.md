# ToothFairy Viewer

1.39 — 파괴 재베이크 메모리 폭증 수정 및 마스크 조작 개선

- 방향 X/Y/Z와 힘을 바꾼 뒤 다시 완료할 때, 주변 배치 하나마다 전체 배치 배열을 복사하던 오류를 수정했습니다. 실제 종료 로그의 할당 실패 스택과 일치하는 경로입니다. 충돌 입력은 각 배치의 변환 하나만 담으며, 4ms 또는 256개 단위로 나눠 준비합니다.
- 방향·힘·재생 길이를 바꾸면 완료 버튼이 ‘다시 완료’로 바뀝니다. 기존 파괴 조각은 그대로 재사용하고 움직임만 베이크합니다. 준비·베이크 중 기존 로딩 HUD와 진행바를 사용하고, 완료 시 정상 재생바로 복귀합니다. 취소하면 이전 결과와 변경값을 유지합니다.
- 브러시와 오브젝트 선택 파괴를 서로 독립된 버튼으로 분리했습니다. 브러시 선택창에는 브러시 도구만 표시합니다.
- 마스크는 기본적으로 보이는 면만 칠합니다. 별도 표시 버튼으로 가려진 면까지 관통하는 모드로 전환할 수 있습니다. 시점을 돌려도 처음 가려져 있던 뒷면에 기본 마스크가 나타나지 않는지 GPU 시험으로 확인했습니다.
- 오브젝트가 선택되어 있으면 그림자 호버가 자동으로 그림자 조작/HUD를 열지 않습니다. 선택을 해제했을 때만 자동 호버가 동작합니다. 메뉴에서 직접 여는 그림자 기능은 유지합니다.
- 셰이더의 동일 크기 RGBA8 중간 결과에서 불필요한 전체 화면 복사 단계를 줄였습니다. Koki 모델에서 유화·흑백 망가·색연필의 이동 화면과 색연필 레이어 내보내기 결과를 픽셀 단위로 비교했습니다. 색감·투명도·효과 강도·출력 품질은 변경하지 않았습니다. 전체 장면 렌더링 비용이 없어지거나 모든 PC에서 무렉이라는 뜻은 아닙니다.

검증: 실제 앱의 최초 파괴→방향/힘 수정→재완료→물리 재생·로딩 종료, 2만 배치 재베이크 입력·취소, 100%/150% HUD, 뒷면 마스크 구분, 셰이더 픽셀/내보내기, 시작/열기 창, 기존 작업 저장 호환성 시험.

1.38 — 조작기 높이·간격·테마 통일, 파괴 진행바와 반복 계산 개선

- 선 두께·조작 속도·화면 이동 슬라이드의 세로 길이와 간격을 통일했습니다. 왼쪽과 아래의 실제 표시 여백도 맞췄습니다. ㄴ자 조작기는 외곽선을 한 번만 그려 모서리의 겹치는 테두리를 제거했습니다. 기존 키보드 연결·복귀·휠·모드 전환은 유지합니다.
- 다크모드 OFF 시 왼쪽 슬라이드·아이콘·값 표시·조이스틱도 밝은 테마로 바뀝니다. 복잡한 배경에서 구분할 수 있는 배경과 테두리는 유지합니다.
- 내보내기 아이콘도 병합·선택·패스 내보내기와 동일하게 호버할 때 오른쪽 HUD를 접습니다. 호버가 끝나면 복구하며, 편집 중 보호 조건은 유지합니다.
- 파괴 계산 중 재생바에 실제 작업 단계와 진행량을 표시합니다. 계산 중에는 재생 위치를 변경할 수 없고, 완료하면 원래 재생바로 돌아옵니다. 기존 로딩 HUD도 유지합니다. 진행량은 현재 단계의 처리량이며, 단계별 작업량이 다른 전체 계산의 가짜 백분율은 사용하지 않습니다.
- 카메라가 그대로인 상태에서 캐릭터 형상이나 오브젝트 배치가 바뀌면, 가시성 후보는 영향을 받은 형상만 갱신합니다. 카메라·검사 조건·형상 구성 변경 시 전체 검사를 다시 수행합니다. 약 19만 배치의 이동·형상 변경·카메라 전환 시험에서 기존 전체 검사와 후보가 하나씩 일치했습니다.
- 셰이더 프로그램을 첫 클릭 순간에만 준비하던 작업을 입력이 없는 동안 한 개씩 미리 준비하도록 변경했습니다. Koki 모델에서 유화·흑백·색연필의 첫 화면과 반복 화면, 색연필 이동 화면과 내보내기를 비교했습니다. 셰이더 효과와 출력 품질은 바꾸지 않았습니다.

검증: 100%·150% 조작기 배치·테마·입력·HUD, 실제 파괴 작업 및 진행량 연결, 공유 배치의 오브젝트 파괴 완료, Koki 색연필 이동·내보내기 픽셀 비교, GPU 마스크 복원, 시작·열기·취소·창 크기 변경, 이전 저장 작업 복원 및 동일 내용 해시 왕복 시험.

캐릭터 조작 시 배경 전체의 GPU 렌더링 비용과 셰이더 자체의 화면 처리 비용은 남아 있습니다. 이번 개선은 불필요한 가시성 재검사와 첫 사용 준비 비용을 줄이며, 모든 사양에서 지연이 없다는 의미는 아닙니다. 원본 SKP·그림자 농도·텍스처 색상·선 두께 설정·투명도·내보내기 품질·저장 형식은 유지합니다.

1.37 — B안 조작기 적용, 파괴 완료·마스크 유지 수정

- 승인한 B안으로 왼쪽 조작기를 변경했습니다. 선 두께·조작 속도는 원형 아이콘, 가는 캡슐 레일, 별도의 값 표시로 구성합니다. 화면 조작 축도 같은 가는 레일로 맞추고, 모드 아이콘 사이에 연결 곡선은 그리지 않습니다. 기존 드래그·휠·복귀·키보드 연결은 유지합니다.

- 선택한 오브젝트에 충돌 레이어를 추가하고 오브젝트 도구에서 완료해도 적용되지 않던 문제를 수정했습니다. 공유 형상 전체의 배치 배열과 선택한 배치 하나의 스냅샷을 비교해 정상 결과를 폐기하던 원인이었습니다. 선택한 배치의 형상·변환·식별자를 검증하고 실제 변경은 계속 거부합니다.
- 미니 HUD가 2초 뒤 닫혀도 칠한 파괴 마스크는 유지합니다. 마스크를 클릭하면 같은 파괴 HUD가 다시 열리며, 다시 여는 클릭으로 마스크를 추가하지 않습니다.
- 파괴 축이 표시되는 시점과 겹치던 환경 준비를 약 4ms씩 나눠 입력 처리 사이에 진행합니다. 준비된 형상·충돌 후보는 다시 복사하지 않고 비동기 작업으로 넘깁니다. 실제 모델의 환경 후보 76,135개를 기존 방식과 하나씩 비교했습니다. 전체 파괴 계산이 4ms라는 의미는 아닙니다.
- 색연필 셰이더의 누적 단계에서 동일한 재질 좌표용 형상을 중복해서 그리지 않도록 재사용합니다. 카메라·장면·가시성·음영 방향 등이 바뀌면 다시 생성합니다. Koki 모델에서 이동 화면과 내보내기 레이어의 RGBA 픽셀 일치를 비교했습니다.
- 최근 작업·파일 열기 카드의 글씨와 썸네일을 매 애니메이션 프레임마다 다시 그리지 않습니다. 고정된 고해상도 카드 이미지를 살짝 확대하는 탄성 호버로 처리하며, 청록색 덮개를 사용하지 않습니다. 확대된 가장자리에서도 호버 판정이 유지됩니다.
- 최근 파일과 파일 열기의 스크롤바에 별도 공간을 확보했습니다. 카드와 겹치지 않으며 스크롤바를 직접 끌어 이동할 수 있습니다.
- 왼쪽 조작기를 창 가장자리로 옮기고 두 축 길이와 배치를 대칭으로 정리했습니다. 이동·회전·둘러보기 아이콘 크기를 조정하고, 복잡한 배경에서도 구분되도록 반투명 어두운 배경과 밝은 테두리를 추가했습니다. 선·아이콘·수치의 윤곽도 함께 사용합니다.
- 선택 오브젝트 HUD에서 짧은 이름도 마지막 글자가 잘리던 문제를 수정했습니다. 실제 글자 그리기 여백을 반영하고 이름과 개수 영역을 분리했습니다. 100%·150% 배율에서 캡슐과 선택 목록을 확인했습니다.

검증: 실제 앱의 마스크 자동 숨김·재진입, 공유 배치 오브젝트 파괴 완료, 실제 충돌 모델 준비, Koki 색연필 화면·내보내기 픽셀 비교, 100%·150% HUD 및 조작기, 시작·파일 열기·취소, 저장 작업 복원 회귀 시험.
기존 색감·그림자 농도·선 두께·투명도·출력 품질·저장 형식은 유지합니다. 모든 PC와 모든 모델에서 지연이 없다는 의미는 아닙니다.

1.36 수정본 — 최근 작업 커서 복구, 파괴 환경 스냅샷 중복 복사 제거

- 최근 작업 및 파일 열기 창의 빈 영역에서 시작 대기 커서가 남는 문제를 수정했습니다. 부모 뷰포트가 커서 처리를 맡았다고 응답하면서 실제 커서를 변경하지 않던 경로를 재현했습니다. HUD가 일반·카드 호버 커서를 직접 처리하고, 검색 입력은 기본 입력 커서를 유지합니다. 포인터를 움직이지 않고 HUD를 열어도 커서가 복구됩니다.
- 새 충돌 로그의 할당 스택에서 파괴 환경 후보 하나마다 해당 파트의 전체 인스턴스 변환 배열을 복사하던 원인을 확인했습니다. 공유 형상 정의는 한 번 준비하고, 각 환경 스냅샷에는 해당 배치 하나의 변환과 식별자만 보관합니다. 원래 장면 식별자와 기존 저장 파일 구조는 유지합니다.
- 실제 충돌 모델의 환경 후보 76,135개 준비를 약 174 ms, 프로세스 추가 메모리 약 91 MiB로 확인했습니다. 별도 512 MiB 제한 시험에서 기존 복사는 116개에서 실패했으나, 수정 방식은 10,000개의 변환을 총 640,000바이트로 보관했습니다. 전체 파괴 계산 시간이 174 ms라는 의미는 아닙니다.
- 카메라와 장면이 그대로인 마스크 그리기는 기존 장면 색상과 깊이를 재사용합니다. 마스크·미리보기만 갱신하고, 강제 전체 재그리기와의 실제 GPU RGBA 픽셀 일치를 검증했습니다. 카메라·장면·레이어 등이 바뀌면 정상 재생성합니다.
- 최근 작업의 마지막 작업 카드와 파일 열기 카드는 청록색 덮개 대신 작은 확대 애니메이션으로 호버를 표시합니다.
- 왼쪽에 선 두께·조작 속도 세로 조절기를 연결하고, 화면 이동·회전 조절기는 얇은 선과 작은 원점, 윤곽 아이콘으로 정리했습니다. 기존 키보드 조작, 조작 속도 값과 연결하며 내보내기에 표시하지 않습니다.

- 시작 시 내보내기 서브메뉴가 자동으로 펼쳐지던 기본 상태를 수정했습니다. 최근 작업을 닫거나 파일 선택을 취소해도 메뉴가 자동으로 열리지 않습니다. 메뉴 아이콘과 Tab으로 여는 동작은 유지합니다.
- 조명·캐릭터 캡슐의 이름을 누르면 뷰어에 종속된 선택 목록이 열립니다. 조명은 현재 조명 목록, 캐릭터는 선택한 캐릭터 목록을 표시합니다. 목록 선택, ESC, 바깥 클릭, 최소화와 100%·150% 배율을 검증했습니다. 캐릭터 여러 개 선택은 유지합니다.
- 파괴 마스크를 GPU에 보낼 때 그림 범위의 높이만큼 행 배열을 만들던 방식을 제거했습니다. 원래 경계선을 보존한 제한된 크기의 연속 검색 인덱스를 사용합니다. 작은 브러시 후 큰 범위의 올가미·다각형을 그릴 때 범위에 비례해 메모리가 급증하는 경로를 수정했습니다.
- 사용되지 않는 대형 CPU 행 캐시를 생성하지 않습니다. 실제 절단·표시·영역 판정은 기존의 연속 경계선을 그대로 사용합니다. 픽셀화나 형상 축소를 하지 않습니다.
- 이미 칠해진 영역의 내부를 다시 칠해도 변화가 없으면 마스크 버전·미리보기 재계산을 요청하지 않습니다. 변경되지 않은 프레임은 GPU 인덱스를 다시 생성·업로드하지 않습니다.
- 메모리 할당 실패 로그에 요청 크기, 당시 여유 메모리, 실행 단계와 모듈 기준 스택 위치를 추가했습니다.
- 이전 1.36의 저장·재질·셰이더 최적화를 유지합니다. 색감·그림자 농도·선 두께·투명도·출력 품질·저장 형식은 변경하지 않았습니다.

확인 범위:
