- [실행 파일](1.35/SkpViewportViewer.exe)
- [변경 내역](1.35/notes.txt)

1.34 이하에서는 앱 업데이트를 이용하세요. 기존 작업 자동 저장은 1.32부터 적용됩니다.

캐릭터를 선택하면 전용 가로 HUD가 표시됩니다. 캐릭터 추가를 길게 누르면 흩뿌리기를 시작합니다. 조작 속도·프록시·그림자 프록시는 설정의 조작 버튼에서 조절합니다.

크랙·파괴는 선택 HUD에서 실행합니다. 크랙 재질은 색상 조절 창으로 열리며, 파괴 방향 조작은 본체 옆 별도 HUD로 표시됩니다. HUD는 뷰어에 종속되며 창 크기 변경·최대화·최소화·로딩에 함께 반응합니다.

뷰어를 닫거나 다른 파일을 열 때 작업을 저장하고, 같은 SKP를 다시 열면 이어갑니다. 원본 SKP는 자동으로 덮어쓰지 않습니다. 최근 목록의 삭제는 해당 뷰어 작업 데이터도 제거하며 원본 SKP는 유지합니다.

태양 설정은 그림자 메뉴 맨 아래에서 조절합니다. 라이트 메뉴는 추가한 조명의 목록과 조절에 집중합니다.
