# ToothFairy Viewer

현재 배포 버전: **1.26**

오브젝트 복사·붙여넣기·이동·회전, SketchUp 데이터 붙여넣기와 팔레트 배치의 불필요한 전체 작업을 줄였습니다. 미리 Ctrl을 누른 이동·회전 복사도 처리합니다.

- [실행 파일](1.26/SkpViewportViewer.exe)
- [변경 내역·측정과 검증 범위](1.26/notes.txt)
- [검증 기록](1.26/validation.json)
- [업데이트 정보](latest.json)

설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.26 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

Koki 모델의 실제 GPU 경로, Ctrl 입력8조합, 다중 선택·반전 부모·동적 구성요소, 42개 패스 이미지 비교, 저장/재열기와 기존 입력 기능 회귀 검사를 수행했습니다. 측정은 입력 처리 구간이며 전체 화면 FPS나 모든 PC의 무지연 보장은 아닙니다.
