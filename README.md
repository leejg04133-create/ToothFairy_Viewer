## 1.04 변경

그림자 묶음 처리 셰이더가 실패했을 때 오류를 지우고 개별 그리기로 넘어가던 처리를 보완했습니다. 병렬 컴파일·연결이 실패하면 같은 소스를 새 셰이더로 한 번 다시 준비하며, 성공하면 기존 묶음 처리를 유지합니다. 별도 컴파일 결과를 적용하지 못했을 때도 원본 소스로 복구합니다. 별도 컴파일의 OpenGL 버전은 뷰어와 일치시킵니다.

오류 주입으로 복구와 화면 일치를 확인했습니다. 실제 EXE의 별도 컴파일, 렌더링 비교 81건, 일반 조명·그림자 내보내기, 업데이트 교체·재시작을 검사했습니다. 실패 단계와 개별 그림자 프로그램 상태, 실제 묶음/개별 호출 수를 로그에 남깁니다.

1.03의 대형 모델 CPU 검사 개선과 기존 업데이트 복구가 포함됩니다. 텍스처·그림자 품질을 낮추는 변경은 없습니다. 기존 친구 PC 로그만으로 해당 셰이더 실패가 실제 지연 원인이었는지는 확정되지 않았습니다. 모든 PC에서 동일한 FPS나 모든 드라이버 오류의 해결을 보장하지 않습니다.

## 이후 배포

새 버전 폴더에 내부 버전도 일치하는 `SkpViewportViewer.exe`를 넣고 `latest.json`의 버전·경로·크기·SHA-256·변경 내역을 함께 갱신합니다. 해당 폴더와 `latest.json`을 커밋하고 GitHub에 푸시해야 사용자에게 업데이트가 표시됩니다. 게시된 버전의 EXE를 다른 내용으로 덮어쓰지 말고 새 버전 번호를 사용합니다.
