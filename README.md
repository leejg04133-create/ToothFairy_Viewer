# ToothFairy Viewer

현재 배포 버전: **1.22**

최초 로딩에서 같은 SKP를 두 번 해석하던 처리를 제거했습니다. 첫 열기와 재열기 모두 SDK 모델 하나를 사용하며, 디스크 UV 캐시에 의존하지 않습니다. 독립 이미지의 무손실 압축도 메모리와 작업 수를 제한해 처리합니다.

- [실행 파일](1.22/SkpViewportViewer.exe)
- [변경 내역 및 측정 조건](1.22/notes.txt)
- [검증 기록](1.22/validation.json)
- [업데이트 정보](latest.json)

기존 버전에서 설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.22 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

280MB 원본 숙소 파일의 실제 첫 열기는 이 PC에서 63.04초 → 39.87초였습니다. Koki 원본도 검사했으며, 정점·UV·면 방향·색상·텍스처 검증값이 일치합니다. 기존 방식과 수정 방식의 SDK 저장 후 재열기 결과도 일치합니다. 색감·그림자 농도·불투명도·선 두께·해상도·내보내기 품질은 유지합니다. 남아 있는 SDK 읽기 비용과 PC 상태에 따라 소요 시간은 달라집니다.
