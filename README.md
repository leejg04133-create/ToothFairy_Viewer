# ToothFairy Viewer

현재 배포 버전: **1.16**

- 실행 파일: [1.16/SkpViewportViewer.exe](1.16/SkpViewportViewer.exe)
- 변경 내역: [1.16/notes.txt](1.16/notes.txt)
- 검증 기록과 한계: [1.16/validation.json](1.16/validation.json)
- 자동 업데이트 정보: [latest.json](latest.json)

무거운 장면 조작 중에만 복잡한 구성요소를 임시 상자로 표시하고 정지하면 원본 패스를 복원합니다. 내보내기는 항상 원본을 사용합니다.
농도, 색감, 선 두께, 불투명도, 해상도와 MSAA 설정은 유지합니다.
단독 패스에 이전 원본 합성의 깊이 효과가 남던 버그를 수정했습니다. 그림자 방향 조작은 수신 면 깊이를 재사용하고 잡은 점/링의 표시를 보장합니다.

이번 버전은 **미서명**이며 Smart App Control 차단 해결 버전은 아닙니다.
정식 서명은 본체와 내장 Live2D 로더 모두에 필요하며, 인증서가 없는 현재 배포본의 차단 해제를 보장하지 않습니다.

설정에서 업데이트 확인 → 다운로드 → 다시 시작을 진행합니다.
구버전의 적용 단계가 실패하면 새 EXE를 직접 받아 기존 뷰어를 종료한 뒤 한 번 교체합니다. `.update-helper.exe`는 직접 전달하는 본 실행 파일이 아닙니다.

이전 배포 폴더는 유지합니다. 새 배포는 새 버전 폴더와 latest.json의 버전·크기·SHA-256을 함께 갱신합니다.
