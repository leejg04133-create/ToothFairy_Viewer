# ToothFairy Viewer

현재 배포 버전: **1.23**

SketchUp의 복사된 클립보드 스냅샷을 직접 가져오도록 복구하고, SDK에서 읽은 동적구성요소 동작을 뷰어 실행부에 다시 연결했습니다. 함께 선택한 구성요소의 동작과 빠른 우클릭 두 번 초기화, 일반 숨김과 동적 숨김의 분리를 유지합니다.

- [실행 파일](1.23/SkpViewportViewer.exe)
- [변경 내역 및 검증 범위](1.23/notes.txt)
- [검증 기록](1.23/validation.json)
- [업데이트 정보](latest.json)

설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.23 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

형식·전송 헤더 조합 50개 및 실제 SDK 파일의 동작 연결·뷰포트 콜백·다중 선택·숨김 보호·저장/재열기 검사를 통과했습니다. 실제 버전별 SketchUp 앱 전체의 Ctrl+C/V UI 검증은 완료하지 않았습니다. 지원하는 기존 동적 동작 범위는 변경 내역을 참고하세요.
