기존 뷰어의 설정에서 업데이트 확인 → 다운로드 → 다시 시작을 진행하면 됩니다. 사용자에게 GitHub 로그인이나 토큰을 요구하지 않습니다. 수동으로 전달할 때도 `1.05/SkpViewportViewer.exe`를 사용합니다. `.update-helper.exe`는 업데이트 보조 파일입니다.

## 1.05 변경

표시 패스를 모두 꺼도 대형 모델의 모든 객체를 검사하던 CPU 작업을 제거했습니다. 텍스처·선만 표시할 때 불필요한 그림자 검사를 생략하고, 필요한 객체 검사의 메모리를 미리 읽어 CPU 대기를 줄였습니다. 변경 사항은 공통 렌더링 코드에 적용되며 텍스처 해상도와 그림자 품질을 유지합니다.

실제 도시 모델의 동일 카메라·화면 크기·MSAA 조건으로 전후 비교했습니다. 측정값과 범위는 검증 기록에 있습니다. 렌더러 CPU 시간 개선이며 앱 전체 FPS 또는 친구 PC의 모든 지연 해결을 뜻하지 않습니다. CPU 모델명과 CPU/GPU 판별 입력량도 기록합니다. 이전 셰이더 오류 복구와 업데이트 복구는 포함됩니다.

## 이후 배포

새 버전 폴더에 내부 버전도 일치하는 `SkpViewportViewer.exe`를 넣고 `latest.json`의 버전·경로·크기·SHA-256·변경 내역을 함께 갱신합니다. 해당 폴더와 `latest.json`을 커밋하고 GitHub에 푸시해야 사용자에게 업데이트가 표시됩니다. 게시된 버전의 EXE를 다른 내용으로 덮어쓰지 말고 새 버전 번호를 사용합니다.
