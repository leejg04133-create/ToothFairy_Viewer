# ToothFairy Viewer

현재 배포 버전: **1.25**

서브메뉴의 얇은 스크롤바, 실제 등록을 통합한 단축키 목록과 검색, 중앙 기능·키 안내를 추가했습니다. 긴 안내 문구의 잘림을 수정하고, 음영 방향 조작 시 음영 패스를 일시 표시한 뒤 기존 화면으로 돌아오도록 연결했습니다.

- [실행 파일](1.25/SkpViewportViewer.exe)
- [변경 내역 및 검증 범위](1.25/notes.txt)
- [검증 기록](1.25/validation.json)
- [업데이트 정보](latest.json)

설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.25 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

100/125/150/200% 배율의 실제 메뉴·검색·글자 배치, 기존 화각 80개 검사, 단축키 콜백·메뉴 이동·좌우 접기, 음영 조작 72개 진입/종료 조합을 검사했습니다. 정확한 검사 범위와 한계는 변경 내역을 참고하세요.
