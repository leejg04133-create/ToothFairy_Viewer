# ToothFairy Viewer

현재 배포 버전: **1.24**

화면을 조작할 때 빨간 바닥 텍스처가 파랗게 바뀌던 프록시 색상 문제를 수정했습니다. 텍스처를 단색으로 표시하는 동안 이미지 대표색을 사용하며, 재질 패스의 원래 색 값과 정지 화면·내보내기는 유지합니다. 대표색은 공유 이미지마다 한 번만 제한된 표본으로 준비합니다.

- [실행 파일](1.24/SkpViewportViewer.exe)
- [변경 내역 및 검증 범위](1.24/notes.txt)
- [검증 기록](1.24/validation.json)
- [업데이트 정보](latest.json)

설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.24 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

제공된 명이방.SKP의 수정 전·후 GPU 렌더링과 25·75단계, 앞뒷면·반전·알파 조합 36개, 정지 후 복구와 각 패스·PSD 내보내기, SDK 회귀 검사를 통과했습니다. 검증의 정확한 비교 범위는 변경 내역에 기록했습니다.
