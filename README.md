# ToothFairy Viewer

현재 배포 버전: **1.17**

- 실행 파일: [1.17/SkpViewportViewer.exe](1.17/SkpViewportViewer.exe)
- 변경 내역: [1.17/notes.txt](1.17/notes.txt)
- 검증과 한계: [1.17/validation.json](1.17/validation.json)
- 업데이트 정보: [latest.json](latest.json)

카메라 변경 후 선 패스에 남던 잘못된 반투명 가림 상태를 수정했습니다. 1.16의 미검증 자동 상자 변환은 되돌렸습니다. 실제 형상과 해당 패스를 표시하며 기존 그림자 깊이 캐시와 텍스처 메모리 최적화는 유지합니다.
색감, 농도, 선 두께, 불투명도, 해상도와 MSAA 설정은 유지합니다.

스케치업과 동일한 프록시 구현이나 저사양 성능 개선 완료를 주장하는 배포가 아닙니다. 공개 Desktop SDK에는 스케치업 내부 프록시 렌더러를 호출하는 API가 없습니다.

설정에서 업데이트 확인 → 다운로드 → 다시 시작으로 진행합니다. 구버전 도우미에서 적용이 실패하면 새 EXE를 직접 받아 기존 뷰어를 종료한 뒤 교체합니다. `.update-helper.exe`는 직접 전달할 본 실행 파일이 아닙니다.
현재 배포본은 미서명이며 Smart App Control 차단 해제를 보장하지 않습니다.
이전 버전 폴더는 유지합니다.
