# ToothFairy Viewer

현재 배포 버전: **1.18**

- 실행 파일: [1.18/SkpViewportViewer.exe](1.18/SkpViewportViewer.exe)
- 변경 내역: [1.18/notes.txt](1.18/notes.txt)
- 검증 기록: [1.18/validation.json](1.18/validation.json)
- 자동 업데이트: [latest.json](latest.json)

편집 → 조작 속도 아래에서 프록시를 조절합니다. 기본 Auto이며 직접 조절하면 사용자 정의로 바뀝니다. 0은 원본, 100은 카메라 조작 중 전체 객체를 상자로 표시합니다. 빨간 Auto 버튼을 누르면 자동으로 복귀합니다.
그림자 패널 맨 위의 그림자 프록시는 기본 100입니다. 값을 내리면 작은 객체 그림자부터 제외하며 0은 화면 그림자 없음입니다.
두 프록시는 화면용입니다. 내보내기는 원래 형상과 전체 그림자 정밀도를 사용합니다. 농도·색감·선 두께·불투명도 등의 기존 설정은 유지합니다.
조작 속도와 새 슬라이더는 길게 누르기로 HUD에 추가하고 우클릭으로 단축키를 설정할 수 있습니다.

설정 → 업데이트 확인 → 다운로드 → 다시 시작. 구버전 도우미에서 적용이 실패하면 새 EXE를 직접 받아 기존 뷰어를 종료한 뒤 교체합니다. `.update-helper.exe`는 직접 전달할 본 실행 파일이 아닙니다.
현재 배포본은 미서명입니다. 이전 배포 폴더는 유지합니다.
