## 1.15 변경

그림자 수신 면의 준비와 겹친 면의 광선 계산을 분리했습니다. 임시 목록의 초기화와 공간 초과 처리는 GPU에서 수행합니다.
흑백 텍스처는 동일한 샘플 값의 채널만 저장하며, 중복 SDK 이미지 읽기와 CPU 가시성 검사를 줄였습니다.
상속 텍스처 UV 조회에서 64비트 SDK ID와 화면 선택 ID가 섞이던 오류도 수정했습니다.
그림자 농도, 텍스처 색감, 선 두께, 불투명도, 해상도와 MSAA 설정을 유지합니다.

Koki 모델, 1920×1000, MSAA 8배의 로컬 렌더러 비교에서 그림자 GPU 평균 78.7→53.3ms,
렌더 완료 평균 142.2→113.4ms, 텍스처 GPU 점유 1003.7→567.1MiB였습니다.
전체 앱의 입력 지연이나 모든 PC의 FPS를 뜻하지 않습니다. 검사 범위와 한계는 검증 기록에 있습니다.

## 이후 배포

새 버전 폴더에 내부 버전이 일치하는 `SkpViewportViewer.exe`를 넣고,
`latest.json`의 버전·경로·크기·SHA-256·변경 내역을 함께 갱신해 커밋하고 푸시합니다.
게시한 EXE는 덮어쓰지 않고 새 버전 번호를 사용합니다.
