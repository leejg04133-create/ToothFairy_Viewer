# ToothFairy Viewer

현재 배포: **1.36 수정본 — 반복 계산·저장 복사 비용 개선, 원본 열기 확인창 수정**

- 원본 열기 확인창의 경고 삼각형을 제거하고 버튼을 ‘열기’로 통일했습니다. 최근 작업·파일 열기 HUD를 숨기지 않고 그 위에서 확인합니다. 취소 시 목록·검색·선택·복귀 경로를 유지합니다.
- 자동 저장 시 큰 파트의 편집 배열과 원시 정점을 나눠 복사하여 UI 스레드의 2ms 작업 예산을 지킵니다. 작은 파트와 이미 압축된 불변 정점은 빠른 복사·공유를 유지합니다.
- 크랙·파괴 저장에서 이미 복사한 형상을 재질 캐시 분리 때 다시 복사하던 비용을 제거했습니다. 공유된 재질 원본과 색상 원본도 한 캡처 안에서 한 번만 분리합니다.
- 캐릭터 관련 선택·공통 조작 대상 계산을 HUD/이동 제어에서 재사용합니다. 대량 선택은 캐릭터마다 전체 선택을 반복 검사하지 않습니다. 선택·계층·삭제·멤버십 변경과 실행 취소 복귀는 다시 검사합니다.
- 마우스 호버만으로 자동 저장을 새로 요청하거나 진행 중 캡처를 폐기하지 않습니다. 드래그·키·휠 입력은 기존처럼 저장 대상이며, 호버의 HUD 표시 시간 갱신은 유지합니다.
- 같은 HUD 배치 함수에서 라이트·그림자 HUD를 연속 두 번 배치하던 중복 호출을 제거했습니다.
- 그림자 농도, 재질 색상, 선 두께, 투명도, 화면/내보내기 품질과 저장 스키마는 변경하지 않았습니다. 저사양 PC 전체의 프레임 속도가 보장된다는 의미는 아닙니다.

측정과 검증:
- 큰 편집 파트 재현 시험에서 단일 캡처 지연 24.34ms → 약 2ms. 크랙·파괴 이력용 복사 재현 시험은 약 59.8ms → 23.4ms.
- Koki 실제 모델 604,554 노드 / 5,703,308 삼각형으로 캡처 시험. 실제 결과는 validation.json 및 소스 폴더의 build_crack/recompute170-all.log에 기록합니다.
- 전체 필드 직렬화 해시 비교, 수정 가능한 원본과의 분리, 공유 캐시 중복 방지, 기존 저장본 호환·복원 재저장 검증.
- 실제 입력 메시지의 호버/드래그/휠 분류, 원본 열기 모달 소유·표시·취소, 100%·150% UI, 시작·최대화·파일/이미지 열기, 그림자 Esc 단계 테스트 통과.


- 최근 작업과 파일 열기 양쪽에서 휴지통을 제거했습니다. 삭제 아이콘과 삭제 클릭 경로가 없으며, 목록을 조작해도 원본 SKP나 저장된 작업을 삭제하지 않습니다.
- 저장된 작업이 있는 카드에는 동일한 크기와 간격의 ‘저장된 작업 있음’ 표시와 ‘원본 열기’ 버튼을 배치합니다. 최근 작업의 마지막 카드·목록 카드, 파일 열기의 격자·목록 보기에 공통 규칙을 사용합니다. 저장 기록이 없는 파일은 일반 열기만 제공합니다.
- 일반 열기는 저장 기록이 있으면 작업 이어 열기, 없으면 원본 SKP 열기입니다. 카드의 원본 열기는 모드 선택 질문 없이 기존 작업 기록 교체 경고로 바로 진입합니다. 취소 시 최근 작업·파일 열기 중 진입했던 화면으로 돌아가며 현재 작업을 유지합니다. 원본 SKP 자체는 덮어쓰지 않습니다.
- 이미지·텍스처·크랙 알파 선택 화면에는 작업 기록 표시나 원본 SKP 열기 버튼이 나타나지 않습니다. 파일 검색·스크롤·창 크기 변경 때 원본 버튼이 다른 파일로 잘못 연결되지 않도록 클릭 영역을 함께 갱신합니다.
- 조작 HUD와 단축키 HUD는 창 밖을 클릭하면 닫힙니다. 창 안 검색·키 변경·슬라이더와 단축키 교체 확인은 유지합니다. 뷰포트·메뉴 등 뷰어 내부의 좌·우클릭을 공통 경로에서 판별합니다.
- 1.35의 작업 저장본 호환 처리, 그림자·음영 Esc 단계 처리, SKP 워터마크와 기존 렌더링 기능을 유지합니다. 저장 형식은 이번 UI 변경으로 바꾸지 않았습니다.


- 작업 복원 중 workspace element count 오류를 수정했습니다. 크랙 양각·음각 상태 두 개가 추가되기 전/후에 같은 schema 3으로 저장되던 두 형식을 구분해 읽습니다. 실제 이전 저장본 두 개(파괴 애니메이션 포함)를 복원하고, 새 저장 후 다시 열어 전체 저장 내용의 해시가 동일한지 검증했습니다. 원본 저장 폴더를 지우거나 초기화하지 않습니다.
- 새 저장은 schema 4로 구분하고 크랙 필드의 저장 순서를 명시적으로 고정했습니다. 반영되는 집합형 데이터의 필드 자료형·순서를 컴파일 시 검사하며, 구조가 달라지면 호환 처리 검토 없이 빌드되지 않도록 기준을 추가했습니다. 기존 개수·해시·데이터 크기 검사는 유지합니다.
- 그림자·음영 Esc 입력에서 키 상태 폴링이 먼저 조작을 끝내고 같은 키의 WM_KEYDOWN이 뒤늦게 HUD를 닫던 중복 처리 순서를 재현·수정했습니다. 첫 누름은 조작 종료, 키를 뗐다가 누른 다음 Esc는 HUD 닫기입니다. 2초 유휴 종료 규칙은 유지합니다.
- 파일 열기에서 저장 기록이 있는 SKP를 선택하면 작업 이어 열기 / 원본 SKP 열기 / 취소를 구분합니다. 원본 열기는 새 작업 자동 저장 시 기존 뷰어 작업 기록이 교체된다는 경고를 다시 확인합니다. 원본 SKP 파일 자체는 변경하지 않습니다. 취소는 현재 화면과 저장 기록을 유지하고 파일 선택으로 돌아갑니다. 최근 작업 목록은 바로 이어 열며 텍스처·크랙 이미지 열기에는 해당 질문이 나타나지 않습니다.
- SKP 워터마크 하늘 패스와 앞선 1.35 기능을 유지합니다.


- 그림자·음영 방향의 첫 Esc는 조작만 끝내고 HUD를 유지합니다. 키를 뗐다가 다시 Esc를 눌렀을 때 HUD를 닫습니다. 같은 누름의 자동 반복이나 중복 전달로 HUD까지 닫히던 경로를 차단하고 유휴 시간을 갱신했습니다. 음영도 마우스를 놓았다는 이유만으로 조작 모드를 끝내지 않습니다.
- 공식 SDK의 SUModelGetStyles, SUStylesGetActiveStyle, SUStyleGetDisplaysWatermark, SUStyleSaveToFile로 현재 SKP 스타일과 표시 설정을 확인하고 포함된 워터마크 이미지를 읽습니다. 원본 컴퓨터의 외부 이미지 경로에 의존하지 않습니다.
- 하늘 패스를 켜면 표시 중인 SKP 워터마크를 하늘 배경으로 합성합니다. 원본 패스에서도 하늘 ON/OFF에 따르며 PNG 등 하늘 내보내기에 같은 결과를 사용합니다. 워터마크가 없거나 표시가 꺼져 있으면 기존 하늘을 유지합니다. 다른 파일로 바꿀 때 이전 워터마크가 남지 않습니다.
- 저장된 이미지 순서, 늘이기·비율 유지·타일·화면 위치, 알파·블렌드 값을 읽습니다. CPU 이미지는 파일 로드 시 한 번 준비하고 GPU 이미지는 최초 사용 후 재사용합니다. 화면 조작·크기 변경·재출력 때 디코딩이나 업로드를 반복하지 않습니다.
- 작업 이어 열기도 저장된 기본 SKP의 스타일에서 워터마크를 복원합니다. 기존 작업 저장 형식을 바꾸지 않았습니다.
- 기존 그림자 이름 버튼의 켜기/끄기, 크랙 방향 축, 2초 미니 HUD 종료, 단축키 도움말과 앞선 1.35 수정 동작을 유지합니다.


- 미니 HUD는 실제 입력이 2초 동안 없으면 부드럽게 사라진 뒤 종료합니다. 선택한 도구·멈춘 호버·숫자 입력 대기만으로 유휴 시간이 계속 초기화되던 조건을 제거했습니다. 실제 드래그나 계산 중에는 유지하며, 사라지는 도중 다시 조작하면 부드럽게 복원합니다.
- 재질·캐릭터·라이트·그림자·크랙·파괴 미니 HUD와 상세 조절에 공통 호버 도움말을 연결했습니다. 기능 이름과 현재 할당한 단축키를 표시하고, 키가 없는 기능에는 가짜 단축키를 표시하지 않습니다. 같은 도움말과 정지 포인터는 화면 픽셀을 재사용합니다.
- 그림자 조작 모드에서 그림자 밖을 우클릭해 좌우로 드래그하면 밝음, 그림자 안에서는 어두움을 조절합니다. 왼쪽은 감소, 오른쪽은 증가이며 카메라·오브젝트 선택·형상은 바꾸지 않습니다.
- 음영 방향을 한 번 누르면 바로 조작에 진입하고 활성 아이콘은 호박색으로 표시합니다. 그림자 방향은 기존 청록색을 유지합니다.
- 어두움이 0이거나 그림자 조작 모드만 남아 HUD가 닫힌 경우에도 실제 그림자 위 0.5초 호버로 HUD를 다시 엽니다. 첫 Esc는 조작을 끝내고 다음 Esc는 HUD를 닫는 규칙을 유지합니다.
- 그림자 HUD의 왼쪽 뒤로가기·닫기를 제거했습니다. 그림자 아이콘 옆에는 ‘그림자’를 표시하며 닫기는 오른쪽 X 하나만 사용합니다.

크랙은 승인 시안의 좌측 알파·재질 세로 구성과 큰 견본을 적용했으며 해당 아이콘 위에 열립니다. 레이어·라이트·캐릭터·충돌 레이어의 추가 버튼은 크기와 여백을 통일했습니다. 브러시는 1~100cm 범위에서 일정하게 조절됩니다. 기존 그림자 서브메뉴를 복구했고, 실제 그림자 위에 0.5초 머물면 청록 강조와 전용 HUD가 켜져 드래그할 수 있습니다. 그리는 중 방향 축은 숨기고 멈추면 다시 표시합니다.

그림자는 별도 하단 HUD로 조작하고 각 설정은 위로 한 개씩 열립니다. 태양 상세·효과·색상 기능을 유지하며 그림자 방향 더블클릭으로 바로 조작합니다.

하단 캡슐은 전체 뷰어 창 중앙에 표시됩니다. 조명은 네 가지 효과 슬라이더를 제공하며 파괴 도구는 작은 아이콘 팝업으로 펼칩니다. 크기·조절·방향은 각각 아이콘으로 열며 세로 크기 슬라이더와 처음으로 재생 버튼을 제공합니다. 라이트·재질 색상창은 링 형태 색상환과 단색 HSB 슬라이더를 사용합니다. 첫 Esc는 캐릭터 방향 조작만 끝내고 두 번째 Esc는 HUD를 닫습니다.

라이트·파괴 메뉴에는 추가 +와 목록이 표시됩니다. 대상을 선택하면 전용 한 줄 HUD로 편집합니다. 파괴 도구는 기본 브러시 아이콘을 눌러 펼치고, 넓은 재생 슬라이드로 시간 위치를 조절합니다. 파괴 방향 기즈모는 유지됩니다.

캐릭터 추가 후 바닥을 길게 누르면 흩뿌립니다. 동작 목록에서 빈 곳을 클릭하면 목록만 닫힙니다. 방향 선택은 Esc 한 번으로 종료하며 캐릭터 HUD를 유지합니다. 조작 속도·프록시는 설정의 조작 HUD에서 조절합니다.

뷰어를 닫거나 다른 파일을 열 때 작업을 저장하고 같은 SKP를 다시 열면 이어갑니다. 원본 SKP를 자동으로 덮어쓰지 않습니다. 최근 목록에서 삭제하면 해당 뷰어 작업 데이터가 제거되며 원본 SKP는 유지합니다.
