# ToothFairy Viewer

현재 배포 버전: **1.20**

시작 큐브와 SKP가 모두 검정으로 보이던 화면 복사 오류를 수정했습니다. 창의 MSAA가 2/4배이고 내부 화면이 8배인 경우를 정상 처리합니다. 내부 렌더 품질·텍스처·그림자·내보내기 설정은 유지합니다.

- [실행 파일](1.20/SkpViewportViewer.exe)
- [변경 내역](1.20/notes.txt)
- [검증 기록](1.20/validation.json)
- [업데이트 정보](latest.json)

1.19 이하 버전에서는 설정 → 업데이트 → 다운로드 → 다시 시작으로 갱신합니다. 직접 전달할 때는 1.20 폴더의 SkpViewportViewer.exe를 사용합니다. 이전 배포 폴더는 유지합니다.

기존 메뉴·카메라·조명 최적화를 포함합니다. 로딩은 모델·텍스처·조명·화면 준비의 큰 항목을 표시하며 기존 Live2D 화면을 유지합니다.

실제 native 0/2/4/8 샘플 및 3840×2096 화면에서 각 패스·재사용·프록시 상태를 검증했습니다. 1.20은 렌더 코드가 검증한 1.19 수정본과 동일하며 버전 정보만 올렸고, 2배 4K와 8배 창 검사를 다시 통과했습니다. 자세한 조건과 한계는 검증 기록에 있습니다.
